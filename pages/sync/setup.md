# 同期を設定する

同期を設定すると、メモをデバイスの中で暗号化してから、自分で用意した同期先へ送ります。同期先にはS3互換ストレージかWebDAVサーバーを使います。同期先の用意は[同期先の準備](/sync/storage)にあります。

同期は最初の画面で「ほかのデバイスと同期する」にチェックを入れるか、あとから「設定」の「同期」ページで設定します。

![同期先の種類、エンドポイント、バケット、リージョン、フォルダを入力する画面](/images/setup-sync.webp)

## 最初のデバイス

1. 「同期先の種類」で「S3互換ストレージ」か「WebDAV」を選ぶ
2. S3互換ストレージなら、エンドポイント・バケット・リージョン・フォルダ・アクセスキーID・シークレットアクセスキーを入力する。WebDAVなら、フォルダのURL・ユーザー名・パスワードを入力する
3. 「接続を確認」を押す
4. 空の同期先なら、「暗号化キーの設定方法」で「自動で生成する」か「自分で入力する」を選ぶ
5. 「作成」（設定の画面では「保存して同期」）を押す

自動で生成した暗号化キーは、保存したあとに一度だけ表示されます。ほかのデバイスを追加するときに入力するので、表示されたら控えておいてください。

![生成した暗号化キーを一度だけ表示するダイアログ](/images/sync-key-generated.webp)

「接続を確認」では、同期先が条件付き書き込みに対応しているかも確かめます。対応していない同期先は同期先にできません。

フォルダを空のまま「接続を確認」を押すと、バケットの直下と、そのすぐ下のフォルダから既存のメモを探します。1か所だけ見つかれば、そこを同期先にします。見つからなければ、バケットの直下に作成します。

## 2台目からのデバイス

同期の設定をエクスポートしておくと、同期先を入力し直さずに追加できます。

1. 同期しているデバイスで、「設定」の「同期」ページの「同期設定をエクスポート」を押す。QRコードが出て、「ファイルに保存」でファイルにもできる
2. 追加するデバイスの最初の画面で「ほかのデバイスと同期する」を選び、「QRコードをスキャン」でQRコードを読み取るか、「設定ファイルを選択」でファイルを選ぶ
3. 暗号化キーを入力して進める

![同期設定をQRコードで表示したダイアログ](/images/sync-export.webp)

エクスポートしたファイルとQRコードは、暗号化キーがないと読めません。エクスポートするときは暗号化キーを入力せず、インポートするときに入力します。QRコードの画像を選んで読み取ることもできます（「QRコードの画像を選択」）。

同期先を手で入力して追加するときは、最初のデバイスと同じ同期先を入力して「接続を確認」を押します。既存のメモが見つかったら、暗号化キーを入力して参加します。

## パスフレーズと暗号化キー

パスフレーズと暗号化キーは別のものです。

| | パスフレーズ | 暗号化キー |
| --- | --- | --- |
| 使う場面 | そのデバイスのロックを解除する | ほかのデバイスを同期に追加する |
| 範囲 | デバイスごとに決める。変えても同期先とほかのデバイスに影響しない | 同期するデバイス全部で共通 |
| 忘れたとき | そのデバイスのデータを削除して、暗号化キーで参加し直す | 「設定」の「同期」ページで再生成する |

暗号化キーはあとから表示し直せません。再生成すると、前のキーでは参加できなくなります。参加済みのデバイスはそのまま同期を続けられます。メモは暗号化し直さないので、前のキーと、再生成する前の`vault.json`のコピーを持っている人は、これからのメモも読めます。

## 同期のタイミング

- 編集の2秒後と、60秒ごとに同期します。ネットワークにつながったときと、アプリの画面に戻ったときにも同期します。
- 「設定」の「同期」ページの「自動で同期する」をオフにすると、自動の同期を止められます。オフでも「今すぐ同期」は使えます。この設定はデバイスごとです。
- 同期に続けて失敗している間は、間隔を5分まで延ばして再試行します。アクセスキーが拒否されたときなど、待っても直らない失敗では自動の同期を止め、理由を表示します。

サイドバーの下に、同期の状態（「同期済み · たった今」「未送信2件」など）が出ます。押すと、「設定」の「同期」ページが開きます。

## 同時に編集したとき

2台で同じメモを同時に編集しても、両方の変更が1つのメモにマージされます。本文はYjs（CRDT）でマージし、タイトルやピン留めなどの項目は、あとに変えた方が残ります。

## アプリのバージョンが違うとき

メモのデータの形を変えたバージョンのアプリで同期すると、古いバージョンのアプリは、更新するまで同期を止めて更新を求めます（[アプリの更新](/reference/updates)）。
