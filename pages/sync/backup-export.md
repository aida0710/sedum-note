# バックアップとエクスポート

「設定」の「データ」ページで、バックアップと、Markdownのインポート・エクスポートを行います。

![「設定」の「データ」ページ。バックアップと、Markdownのインポートとエクスポートの欄がある](/images/settings-data.webp)

## バックアップ

「バックアップをエクスポート」で、このデバイスのメモ・ノートブック・添付ファイルを、暗号化したまま1つのファイルにエクスポートします。

戻すときは、新しく入れたアプリの最初の画面で「バックアップから復元」を選び、バックアップファイルと、エクスポートしたときのパスフレーズを入力します。

メモの履歴と、AIチャットの履歴、AIのAPIキーは、バックアップに入りません。

## Markdownのインポート

「Markdownをインポート」で、Markdownファイル（`.md`）か、それをまとめたzipファイルを読み込みます。zipの中のフォルダはノートブックに、相対パスで参照している画像やファイルは添付ファイルになります。

## エクスポート

すべてのメモを、Markdown・HTML・テキストのどれかでエクスポートできます。ノートブックごとのフォルダに分けたzipファイルになります。1つのメモだけをエクスポートするときは、メモの「…」の「エクスポート」で形式を選びます。

| 形式 | 中身 |
| --- | --- |
| Markdown | 見出しや表などの書式を、Markdownの記法で残します。添付ファイルがあれば、まとめてzipにします |
| HTML | ブラウザで開ける形式で、書式を残します。添付ファイルがあれば、まとめてzipにします |
| テキスト | テキストだけです。書式と添付ファイルは入りません |

エクスポートしたファイルは暗号化されないため、誰でも読めます。保存場所に注意してください。Markdownでどの書式がどう書き出されるかは、[Markdownとの対応](/reference/markdown)にあります。

## 印刷とPDF

メモの「…」の「印刷・PDFで保存」で印刷できます。OSの印刷の画面から、PDFとして保存することもできます。Androidのアプリでは使えません。
