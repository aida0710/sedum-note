# AIチャット

AIとチャットして、メモについて質問したり、要約や書き直しを頼んだりできます。AIはメモを探して読み、作成や編集もできます（MCPサーバーと同じ操作です）。

![右の欄でAIチャットを開き、メモの要約を受け取った画面](/images/ai-chat.webp)

## 有効にする

AIチャットは既定でオフです。

1. 「設定」の「AI」ページで「AIチャットを使う」をオンにする
2. 「接続先」を選ぶ。「Claude API」か、「OpenAI互換のエンドポイント」（Ollamaなどのローカルのモデル、OpenAIのAPIなど）
3. APIキーを入力する。OpenAI互換のエンドポイントでは、エンドポイントのURL（`/chat/completions`の手前まで）も入力する。例: Ollamaは`http://127.0.0.1:11434/v1`、OpenAIは`https://api.openai.com/v1`
4. 「保存して接続を確認」を押す。接続先から使えるモデルの一覧を取得できたときだけ保存する
5. 「モデル」で、一覧から使うモデルを選ぶ

![「設定」の「AI」ページ。接続先、APIキー、モデル、AIに任せるメモの操作の欄がある](/images/settings-ai.webp)

Web版からローカルのサーバーに接続するときは、サーバー側でWeb版のページからの接続（CORS）を許可する必要があります。

## チャットを開く

メモの「…」の「AIチャット」か、Ctrl+Alt+A（Macは⌘）で開きます。PCでは画面の右の欄に、スマホではダイアログに出ます。

- 発言にはコンテキストとして、開いているメモ、選択しているテキスト、入力欄で「@」を打ってタイトルで探したメモを渡せます。何を渡すかは入力欄の上に出ます。
- チャットの上で、そのチャットで使うモデルを切り替えられます。
- 回答は見出し・表・箇条書き・コードなどの書式を付けて表示します。リンクはWebページとメールのリンクだけを外部のブラウザで開きます。画像は読み込みません。
- 回答はコピーするか、開いているメモのカーソルの位置か末尾に入れられます。コピーと挿入には、Markdownの文を使います。
- 停止のボタンは回答を受け取っている間も、承認を待っている間も、ツールを動かしている間も使えます。

文字を選んで出る書式のボタンの「AIに依頼」からは、選んだ所の言い換え・要約・英語や日本語への翻訳を頼めます。回答で、選んだ所を置き換えられます。

## AIによるメモの操作

AIは回答を考える途中で、メモの検索・読み取り・作成・本文の編集・末尾への追加・タイトルやノートブックの変更・ゴミ箱への移動と復元・ノートブックの作成と削除を、続けて何回でも行えます。行った操作は回答の中に1行ずつ出ます。行を押すと、そのメモを開きます。

「設定」の「AI」ページの「AIに任せるメモの操作」で、操作の種類ごとに「許可しない」「毎回確認」「確認せずに許可」を選びます。

| 操作 | 既定 |
| --- | --- |
| メモの検索・読み取り | 確認せずに許可 |
| メモとノートブックの作成・編集 | 毎回確認 |
| ゴミ箱への移動・ノートブックの削除 | 毎回確認 |
| 完全な削除 | 許可しない |

「毎回確認」の操作は回答の下のカードで中身を確かめてから、「許可」か「拒否」を選びます。本文の編集は削除する行と追加する行の差分で表示します。1つの回答に変更がいくつかあるときは1枚のカードにまとまり、選んだものだけを行えます。承認を待つ間に対象のメモが変わったら、その変更は行いません。

![AIが提案した本文の変更を、行ごとの差分で表示した承認のカード](/images/ai-approval.webp)

チャットの下の「このチャットでは、メモの作成・編集に承認を求めない」をオンにすると、そのチャットの間だけ、作成・編集を「確認せずに許可」にします。

本文の編集で置き換わるのは、変わったブロックだけです。変えていないブロックの書式（文字色など）は残ります。編集する前の状態と編集した結果は、メモの履歴に残ります（編集した結果は「AIチャットの編集」）。開いているメモなら、エディタの元に戻す（Ctrl+Z）でも戻せます。AIが読んだあとで書き換えられたメモは、AIが読み直すまで本文を書き換えさせません。

OpenAI互換の接続先がツール（function calling）に対応していなければ、ツールを使わず、渡したメモだけをもとに回答します。

## チャット履歴

チャットは、回答が届くたびに、このデバイスのこのスペースに暗号化して保存します（新しいものから50件まで）。チャットの上の「チャット履歴」から開いて続きを話せ、1件ずつ削除できます。開き直したチャットでは、AIは前に読んだメモの本文を覚えていないので、必要なら読み直します。チャット履歴は同期とバックアップに入りません。

渡したメモはチャットの中に本文のコピーを残さず、送るたびに今の本文を読みます。削除したメモは削除されたことだけをAIに伝えます。

## 送られるデータ

渡したメモの本文、選択したテキスト、AIが読んだメモの本文は、暗号化されない形で接続先に送られます。ローカルのLLMを接続先にすれば、このデバイスの外には出ません。添付ファイルの中身は送りません。

APIキーはこのデバイスの中で暗号化して保存します。同期とバックアップには入りません。
