# Web版

Web版はインストールせずにブラウザで使えます。[https://aida0710.github.io/sedum-note/](https://aida0710.github.io/sedum-note/)を開きます。

## 保存される場所

メモはそのブラウザの中（そのブラウザのそのプロファイル）に、暗号化して保存されます。ブラウザのサイトのデータを削除すると、そのブラウザのメモも消えます。同期していれば、暗号化キーで参加し直すと戻ります。

## アプリとの違い

| 項目 | Web版 |
| --- | --- |
| 同期 | 同期先にCORSの設定が要ります（[同期先の準備](/sync/storage)） |
| 期限の通知 | 開いていてロックを解除している間だけ。スマホのブラウザでは通知を表示できません |
| 別のウィンドウ | PCのブラウザで使えます。ロックの解除は、メモを開いた別のウィンドウと元のウィンドウの間でだけ伝わります |
| MCPサーバー | ありません（PCのアプリだけ） |
| AIチャット | 使えます。ローカルのサーバーに接続するには、サーバー側でCORSを許可します |
| 更新 | 開くたびに最新のものを読み込みます |

## キーボードショートカット

ブラウザが使うキー（Ctrl+N、Ctrl+T、Ctrl+W、Ctrl+Tab）はWeb版に届かないため、それらの操作はAltを加えた組み合わせを既定にしています（[キーボードショートカット](/customize/shortcuts)）。

## 公開先

Web版はGitHub Pagesで公開しています。開くと、GitHubにアクセスの情報が伝わります。公開するのは、リリースしたバージョンの画面です。
