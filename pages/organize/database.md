# プロパティとデータベース表示

ノートブックにプロパティ（状態・期日・数などの項目）を決めると、そのノートブックのメモに値を付けられます。

## プロパティを決める

ノートブックの「…」のメニューで「プロパティ」を選び、「プロパティを追加」で項目を足します。種類は次の5つです。

| 種類 | 値 |
| --- | --- |
| テキスト | 文字 |
| 数値 | 数 |
| 日付 | 年月日 |
| セレクト | 決めた選択肢から1つ |
| チェックボックス | オンかオフ |

名前と選択肢は、Enterか「保存」で保存します。プロパティを決めたノートブックのメモには、タイトルの下に値を入れる欄が出ます。

## データベース表示

PCの画面では、ノートブックの「…」のメニューの「データベース表示」で、ノートブックのメモを一覧にできます。レイアウトは2つです。

- テーブル: プロパティを列にして並べます。列の見出しの右端の「＋」から、プロパティを追加できます。
- ボード: セレクトのプロパティの値ごとに列を分けて並べます。

![メモをタイトル・状態・期日・更新日時の列で並べたテーブル](/images/database-table.webp)

![状態の値ごとに列に分けたボード](/images/database-board.webp)

どちらのレイアウトでも、値はその場で変えられます。並べ方と見え方は、ノートブックに保存されます。テーブルの下とボードの列の下の「メモを作成」では、タイトルを入力すると、そのノートブックにメモができます。ボードでは、その列の値が入ります。

ボードを使うには、種類がセレクトのプロパティが1つ以上要ります。

## Markdownにしたとき

Markdownでエクスポートすると、プロパティは本文の先頭に項目として書き出されます。インポートすると、テキストのプロパティになります。
