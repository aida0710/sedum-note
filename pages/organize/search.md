# 検索とコマンドパレット

## メモの中を検索・置換する

Ctrl+F（Macは⌘+F）で、開いているメモの中を検索します。一致した所に色が付きます。

![メモの中で「索引」を検索し、置換の欄も開いた画面](/images/find-replace.webp)

- 検索の欄の右のボタンで、大文字と小文字の区別、単語単位、正規表現を切り替えられます。
- 「置換を表示」のボタンか、Ctrl+R（Macは⌘+R）で置換の欄を開きます。一致した所を1つずつ置換するか、「すべて置換」でまとめて置換します。
- 正規表現では、置換後のテキストに`$1`のようにグループの中身を使えます。

## すべてのメモを検索する

サイドバーの上の検索のボタンか、Ctrl+Shift+F（Macは⌘+Shift+F）で、タイトルと本文を検索します。ひらがなとカタカナは同じ文字として扱います。

![サイドバーで「#todo」を検索した結果](/images/sidebar-search.webp)

| 書き方 | 意味 |
| --- | --- |
| `#タグ` | そのタグの付いたメモに絞り込む |
| `notebook:名前` | そのノートブックと、その中のノートブックのメモに絞り込む |
| `"空白を 含む 語句"` | 空白を含む語句を1つの語として探す |

結果の行には、本文の中で一致した所が前後の文と一緒に出ます。「この検索を保存」で名前を付けて保存すると、サイドバーの「保存した検索」から同じ検索を開けます。保存した検索は同期されます。

## コマンドパレット

Ctrl+K（Macは⌘+K）でコマンドパレットを開きます。メモ（タイトルと本文）・ノートブック・タグ・設定の項目・操作をまとめて探せます。

![コマンドパレットで「沖縄」を検索した画面](/images/command-palette.webp)

- 何も入力していないときは、更新が新しいメモ（8件まで）と、よく使う操作（新しいメモ、設定を開く、期限の一覧）が、ショートカットのキーと一緒に並びます。
- 設定の項目を選ぶと、その設定のページのその項目へ移ります。
- 「>」で始めると、操作だけを探します。
- 入力した語句と同じタイトルのメモが無ければ、その語句をタイトルにして新しいメモを作れます。
