# Markdownとの対応

Markdownのエクスポート・インポートと、Markdownの貼り付けでは、次の書き方を使います。

## 書式とブロック

| 書式 | Markdown |
| --- | --- |
| 見出し、リスト、チェックリスト、引用、コード、表、区切り線、太字、斜体、リンク | 一般的なMarkdown（GFM）の書き方 |
| ハイライト | `==文字==` |
| 数式 | 行の中は`$...$`、独立した行は`$$...$$` |
| 図（Mermaid） | 言語が`mermaid`のコードブロック |
| コールアウト | `> [!note]`、`> [!tip]`、`> [!warning]`、`> [!danger]` |
| 脚注 | `[^1]`と、本文の下の`[^1]: 脚注の文` |
| 手書き・図形 | 言語が`sedum-drawing`のコードブロック |
| 項目の期限 | 項目の文字の中の`📅 2026-11-20 09:00` |
| プロパティ | 本文の先頭の項目。インポートすると、テキストのプロパティになる |

## 添付とリンク

| 種類 | Markdown |
| --- | --- |
| 画像 | `![名前](添付のパス)` |
| ファイル | `[名前](添付のパス)`だけの段落 |
| メモへのリンク | `[タイトル](sedum-note://note/<メモのID>)` |
| ブロックへのリンク | `[タイトル](sedum-note://note/<メモのID>#<ブロックのID>)`。リンク先のブロックの行の末尾に` ^<ブロックのID>` |
| ブロックの埋め込み | `![タイトル](sedum-note://note/<メモのID>#<ブロックのID>)`だけの段落 |

Markdownのzipをインポートすると、相対パスで参照している画像とファイルは添付になり、zipの中のフォルダはノートブックになります。

## Markdownにしたときに残らないもの

- 文字色と、表のセルの背景色
- 表の列の幅。結合したセルは、左上のセルにだけ中身が残ります
- 段組み。左の段から順に、上から並べて書き出します
