# アプリの更新

## 更新のしかた

| 環境 | 更新 |
| --- | --- |
| PCのアプリ | ロックを解除したときに、新しいバージョンがあるかを確かめます。あれば「設定」の「更新」ページの「更新して再起動」でダウンロードして入れ替えます。入れ替える前に、配布元の署名を確かめます |
| Androidのアプリ | 新しいバージョンがあることを知らせ、「リリースのページを開く」でGitHubのリリースのページを開きます |
| Web版 | 開くたびに最新のものを読み込みます |

「設定」の「更新」ページの「更新を確認する」を押すと、いつでも確かめられます（Web版も）。最新なら、確かめた時刻と一緒にそう表示します。確かめられなかったとき（ネットワークにつながっていないときなど）は、最新とは表示せず、確かめられなかったことを表示します。Web版で新しいバージョンが見つかったら、「読み込み直して更新」でページを読み込み直します。

確かめるときは、GitHubに接続します。送るのはアプリのバージョンとOSの種類だけで、メモの中身は送りません。ロックを解除したときの確認は、「設定」の「更新」ページで止められます。

## メモのデータの形のバージョン

メモのデータの形（本文の書式や、記録の書き方）を変えたバージョンでは、データの形のバージョンを上げます。古いバージョンのアプリで新しい形のメモを開くと、古いアプリが知らない書式を本文から消してしまうためです。

- どれか1台を新しいバージョンに上げて同期すると、ほかのデバイスは、アプリを更新するまで同期を止めて更新を求めます。
- 新しいバージョンのアプリはロックを解除したときに、手元のメモを新しい形に移し替えます。

決まりの詳細は開発者向けの[docs/data-format.md](https://github.com/aida0710/sedum-note/blob/main/docs/data-format.md)にあります。
