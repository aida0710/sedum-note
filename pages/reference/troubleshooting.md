# トラブルシューティング

## 同期先に接続できない

| 表示 | 確かめること |
| --- | --- |
| ストレージに接続できません | エンドポイントが正しいか、ネットワークに接続しているか。Web版では、バケットにCORSを設定してあるか（[同期先の準備](/sync/storage)） |
| ストレージへのアクセスが拒否されました | アクセスキーと、その権限 |
| バケットが見つかりません | バケット名とリージョン |
| ExposeHeadersにETagを追加してください | バケットのCORS設定の`ExposeHeaders`に`ETag`があるか |
| 条件付き書き込みに対応していない | 同期先が`If-Match`・`If-None-Match`に対応していません。別のストレージを使ってください |
| エンドポイントはhttps://で始めてください | エンドポイントのURL |

## 暗号化キーが正しくない

暗号化キーは同期先を作成したときに表示されたもの、または自分で入力したものです。あとから表示し直せません。わからないときは、同期しているデバイスの「設定」の「同期」ページで再生成し、新しいキーで参加します（[同期を設定する](/sync/setup)）。

## 新しいバージョンのアプリで作成されたメモ

「このメモは、新しいバージョンのアプリで作成されています」と表示されたら、アプリを更新してください。古いバージョンのアプリは、同期先のデータの形が新しいと同期しません（[アプリの更新](/reference/updates)）。

## v0.2以前のアプリで作成した同期先

v0.2以前のアプリで作成した同期先は、暗号化キーが無いため、今のアプリでは使えません。そのデバイスにメモが残っていれば、「設定」の「同期」ページの「同期先を変更」で空のフォルダを同期先にすると、メモをそこへ送信し直し、前の同期先の添付もコピーします。ほかのデバイスは新しい同期先に参加し直します。

## パスフレーズを忘れた

パスフレーズがないと、そのデバイスのメモは開けません。ロック解除の画面の「パスフレーズを忘れたとき」から、このデバイスのデータを削除して始め直します。同期していれば、暗号化キーで参加し直すと、同期先のメモが戻ります（[ロックとパスフレーズ](/security/lock)）。

## 開けないデータがある

「設定」に「開けないデータが◯件あります」と出たときは、データが破損しているか、別のパスフレーズで作成されたデータです。

- 同期しているなら、同期先のデータが破損していなければ、このデバイスのデータを削除して同期先に参加し直すと開けます。まだ送信していない変更は失われるため、先にバックアップをエクスポートしてください。
- 同期していないなら、そのデータをほかの場所から復元することはできません。ほかのメモはそのまま使えます。

## 保存容量が足りない

「このデバイスの保存容量が足りません」と出たら、不要なメモや添付ファイルを削除してから、もう一度試してください。

## カスタムCSSで画面が操作できない

ロック解除の画面の「カスタムCSSをオフにして開く」で開きます。
