# キーボードショートカット

PCの画面のショートカットの一覧です。表はWindowsとLinuxのキーです。Macでは、CtrlをCommand（⌘）に、AltをOption（⌥）に読み替えます。

## どこでも使えるキー

| 操作 | キー |
| --- | --- |
| コマンドパレット | Ctrl+K |
| メモを作成 | Ctrl+Alt+N |
| メモを検索 | Ctrl+Shift+F |
| 開いているメモの中を検索 | Ctrl+F |
| 開いているメモの中を置換 | Ctrl+R |
| 次のタブ・前のタブ | Ctrl+Alt+→・Ctrl+Alt+← |
| タブを閉じる | Ctrl+Alt+W |
| 閉じたタブを開き直す | Ctrl+Alt+Shift+T |
| 設定を開く | Ctrl+, |
| グラフ表示 | Ctrl+Alt+G |
| 期限の一覧 | Ctrl+Alt+E |
| AIチャット | Ctrl+Alt+A |
| フォーカスモード | Ctrl+Alt+F |
| タイプライターモード | Ctrl+Alt+Shift+F |
| ロック | Ctrl+L |

## 本文の中のキー

| 操作 | キー |
| --- | --- |
| 今日の日付 | Ctrl+Alt+D |
| 現在の日時 | Ctrl+Alt+Shift+D |
| カーソルのある項目・セクションにズーム | Ctrl+. |
| 1つ上の階層にズームアウト | Ctrl+Shift+.（Escでも戻る） |
| すべて折りたたむ・すべて展開 | Ctrl+Alt+[・Ctrl+Alt+] |
| ブロックを上に移動・下に移動 | Ctrl+Shift+↑・Ctrl+Shift+↓ |
| ブロックを複製 | Ctrl+D |

太字（Ctrl+B）・斜体（Ctrl+I）・下線（Ctrl+U）、元に戻す（Ctrl+Z）などの書式と編集のキーも使えます。

## 表の中のキー

| 操作 | キー |
| --- | --- |
| 下に行を追加・上に行を追加 | Ctrl+Enter・Ctrl+Shift+Enter |
| 右に列を追加・左に列を追加 | Ctrl+Alt+Enter・Ctrl+Alt+Shift+Enter |

## サイドバーのキー

| 操作 | キー |
| --- | --- |
| 前後の行へ移る | ↑・↓ |
| 一覧を開く・閉じる | →・← |
| メモを開く | Enter |
| メモを開かずに選ぶ | Shift+クリック、Shift+↑↓ |
| 別のウィンドウで開く | Ctrl+クリック |

## キーを変える

「設定」の「ショートカット」ページで、どこでも使えるキーと、本文・表の中のキーを変えられます。キーのボタンを押してから、新しいキーの組み合わせを押します。Escでやめ、Backspaceでキーなしにします。「既定に戻す」で、1つずつか、まとめて既定のキーに戻せます。

![「設定」の「ショートカット」ページ。操作ごとにキーのボタンが並ぶ](/images/settings-shortcuts.webp)

- 組み合わせにはCtrl（Macは⌘）を含めます。
- ほかのショートカットで使っているキーと、文字の編集やコピーなどに使うキーは割り当てられません。先にほかのショートカットのキーを変えてください。
- 書式のキー（太字など）は変えられません。
- 変えたキーはこのデバイスだけで使います。

メモの「…」のメニューでも、項目の右にキーが出ます。

ここに書いたキーは既定のキーです。ブラウザが使うキー（Ctrl+N、Ctrl+T、Ctrl+W、Ctrl+Tab）はWeb版に届かないため、それらの操作はAltを加えた組み合わせを既定にしています。
