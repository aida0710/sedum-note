# テンプレート

よく使う形のメモをテンプレートにしておくと、そこから新しいメモを作れます。

## テンプレートを作る

メモの「…」のメニューで「テンプレートにする」を選びます。テンプレートにしたメモは、ふつうの一覧には出ず、サイドバーの「テンプレート」に並びます。元に戻すときは「テンプレートを解除」を選びます。

## テンプレートを使う

- テンプレートを開き、「このテンプレートからメモを作成」を押すと、新しいメモができます。
- 本文で「/」を打つと、メニューの「テンプレート」にテンプレートが並びます。選ぶと、テンプレートの本文をその場に入れます。

## 変数

テンプレートのタイトルと本文に次の変数を書いておくと、メモを作るときと「/」で入れるときに、そのときの値に置き換わります。テンプレートそのものは変わりません。

| 変数 | 置き換わる値 |
| --- | --- |
| `@date` | 日付 |
| `@time` | 時刻 |
| `@datetime` | 日時 |
| `@title` | メモのタイトル。作るときはできあがるメモのタイトル、「/」で入れるときは入れる先のメモのタイトル |

日付と時刻の形式は、「設定」の「一般」の「日付と時刻の形式」で、「2026-11-13」の形か、画面の言語の書き方かを選べます。コードの中と、`foo@date.example`のように英数字に続く`@`は置き換えません。

たとえば、タイトルを「`@date` 定例」にしたテンプレートからメモを作ると、「2026-11-15 定例」のようなタイトルになります。
