# 表

表は「/」のメニューの「表」で入れます。Markdownの表を貼り付けても、表になります。

![表のセルにカーソルを置き、上のバーから表のメニューを開いた画面](/images/editor-table.webp)

## 表のメニュー

カーソルが表の中にある間は、上のバーに表のメニューのボタンが出ます。スマホでは、画面の下のバーに出ます。メニューでは次の操作ができます。

- 上・下に行を追加、左・右に列を追加
- 行を上下へ、列を左右へ移動
- この列で昇順・降順にソート
- この列で行をフィルター（列に含まれるテキストで絞り込む）
- セルを結合、セルを分割
- ヘッダー行、ヘッダー列の切り替え
- 列を左揃え・中央揃え・右揃え
- セルの背景色
- 行・列・表の削除

フィルターは表示だけを絞り込みます。メモを開き直すと解除されます。

## 列の幅を変える

列の境目をドラッグすると、列の幅を変えられます。

## キーボードで行と列を足す

表の中では、次のキーで行と列を追加します（Macは⌘）。

| キー | 操作 |
| --- | --- |
| Ctrl+Enter | 下に行を追加 |
| Ctrl+Shift+Enter | 上に行を追加 |
| Ctrl+Alt+Enter | 右に列を追加 |
| Ctrl+Alt+Shift+Enter | 左に列を追加 |

キーは「設定」の「ショートカット」で変えられます（[キーボードショートカット](/customize/shortcuts)）。

## Markdownにしたとき

Markdownでエクスポートすると、列の幅と、セルの背景色は残りません。結合したセルは、左上のセルにだけ中身が残ります。
