# リンクと埋め込み

メモからほかのメモや、メモの中のブロックへリンクできます。

## メモへのリンク

「/」の「メモへのリンク」を選び、リンクするメモを選びます。PCの画面では、サイドバーのメモを本文へドラッグしても、落とした所にリンクが入ります。

リンクには、リンク先のタイトルが出ます。リンク先のタイトルを変えると、リンクの表示も変わります。リンクにポインターを乗せると、リンク先のタイトルと本文の始めが出ます。

![リンクにポインターを乗せて、リンク先の本文の始めを出した画面](/images/editor-link-preview.webp)

## バックリンク

リンクされたメモの下には「このメモへのリンク」として、リンクしているメモの一覧が出ます。

![メモの下に出た「このメモへのリンク」の一覧](/images/editor-backlinks.webp)

## ブロックへのリンク

「/」の「ブロックへのリンク」で、メモの中の段落・見出し・箇条書きの項目へリンクできます。リンクには、そのブロックの今の文字が出ます。押すとメモを開き、そのブロックまでスクロールします。リンクしたブロックを動かしたり書き換えたりしても、リンクは切れません。

## ブロックの埋め込み

「/」の「ブロックの埋め込み」で、ほかのメモ（か同じメモ）のブロックを、本文の中に表示できます。元のブロックを書き換えると、埋め込みの表示も変わります。埋め込みの側では書き換えられません。HTMLとテキストでエクスポートすると、元のメモのタイトルだけが残ります。

## グラフ表示

PCの画面の「グラフ表示」（Ctrl+Alt+G）では、メモ同士のリンクのつながりを図で見られます。サイドバーの上のボタンからも開けます。

![メモを点、リンクを線で結んだグラフ表示](/images/graph.webp)

## Markdownでの書き方

リンクと埋め込みは、Markdownでは次の形で書き出し、読み込みます。

| 種類 | 形 |
| --- | --- |
| メモへのリンク | `[タイトル](sedum-note://note/<メモのID>)` |
| ブロックへのリンク | `[タイトル](sedum-note://note/<メモのID>#<ブロックのID>)`。リンク先のブロックの行の末尾に` ^<ブロックのID>`が付きます |
| ブロックの埋め込み | `![タイトル](sedum-note://note/<メモのID>#<ブロックのID>)`だけの段落 |
