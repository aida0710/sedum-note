# エディタの基本

本文は段落・見出し・リスト・表などのブロックを並べて書きます。PCの画面では、書式のボタンを本文の上に並べず、必要なときだけメニューを出します。スマホでは、画面の下に書式のボタンが並びます。

## 「/」でブロックを入れる

本文で「/」を打つと、ブロックの種類のメニューが開きます。続けて文字を打つと絞り込めます。メニューの上には、最近使った項目が出ます。

![「/」で開いたブロックの種類のメニュー](/images/editor-slash-menu.webp)

| まとまり | 入れられるもの |
| --- | --- |
| 基本 | テキスト、見出し1〜6、箇条書きリスト、番号付きリスト、チェックリスト、引用、区切り線 |
| ブロック | コード、表、コールアウト（情報・ヒント・注意・警告）、2段組み・3段組み、数式、図（Mermaid）、手書き・図形 |
| メディア | 画像、ファイル、録音、書類のスキャン、埋め込み（動画・Webページ） |
| 挿入 | 今日の日付、現在の日時、期限、脚注、クエリ |
| リンク | メモへのリンク、ブロックへのリンク、ブロックの埋め込み |
| テンプレート | テンプレートにしたメモ（[テンプレート](/editor/templates)） |

録音の機能が無い環境では、「録音」はメニューに出ません。

それぞれのブロックは[表](/editor/tables)、[ブロックの種類](/editor/blocks)、[リンクと埋め込み](/editor/links)、[画像・ファイル・録音](/editor/attachments)で説明しています。

## 文字を選んで書式を付ける

PCの画面で文字を選ぶと、その上に書式のボタンが出ます。見出し、太字、斜体、下線、ハイライト、文字色、リンクと、「AIに依頼」があります。「AIに依頼」では、選んだ所の言い換え・要約・英語や日本語への翻訳を頼めます（[AIチャット](/ai/chat)）。

![本文の段落を選び、その上に書式のボタンが出た画面](/images/editor-selection-toolbar.webp)

カーソルが表の中にある間は、上のバーに表のメニューが出ます。

## Markdownの書き方で入力する

行の先頭で次のように打つと、そのブロックに変わります。

| 打つ文字 | 変わるもの |
| --- | --- |
| `# `〜`###### ` | 見出し1〜6 |
| `- ` | 箇条書きリスト |
| `1. ` | 番号付きリスト |
| `[ ] ` | チェックリスト |
| `> ` | 引用 |
| ```` ``` ```` | コード |
| `---` | 区切り線 |

日本語入力をオンにしたまま「・ 」「ー 」「１． 」と打っても、リストになります。変わった直後にBackspaceを押すと、打った文字に戻ります。「1.」と書きたいだけのときに使います。

Markdownの文字を貼り付けると、見出し・リスト・表・コードなどの書式になります。コードの中に貼り付けたときと、書式付きでコピーしたものは、そのまま貼り付けます。

## リストの深さ

箇条書きの項目でTabを押すと深く、Shift+Tabで浅くなります。番号は深さごとに「1.」「a.」「i.」、点は「●」「○」「■」と変わります。コードの中のTabは字下げです。それ以外の所でTabを押しても、カーソルが本文の外に出ることはありません。

## ブロックを動かす

PCの画面では、ブロックにポインターを乗せると、左に「＋」とハンドルが出ます。

- ハンドルをドラッグすると、ブロックを並べ替えられます。箇条書きの項目は子の項目ごと動きます。
- ハンドルを押すと、ブロックのメニューが開きます。見出し・箇条書き・引用・コードなどへの変換（何行かを選んでいれば、まとめて変換）、上下への移動、複製、削除ができます。
- 「＋」を押すと、すぐ下に行を追加して「/」のメニューを開きます。

![ブロックのハンドルを押して開いた、変換と移動のメニュー](/images/editor-block-menu.webp)

キーボードでは、Ctrl+Shift+↑↓でブロックを上下に動かし、Ctrl+Dで複製します（Macは⌘）。

## そのほか

- 長いメモは上のバーの「目次」で見出しの一覧を出せます。
- 見出しと子の項目を持つ箇条書きは、折りたためます（[折りたたみとズーム](/editor/outline)）。
- タイトルの上の右に、本文の文字数と更新日時が出ます。文字を選んでいる間は、選んだ文字数も出ます。
- 本文の配置（左寄せ・中央寄せ・右寄せ）と、文字の大きさ・行間は、[テーマと表示](/customize/appearance)で変えられます。
