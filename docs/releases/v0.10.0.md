画面の使いやすさを見直しました。スマホでは、並んだボタンの端を押すと隣のボタンが反応することがなくなり、押せる範囲を広げました。薄くて読みにくかった文字を濃くし、入力の誤りは欄のすぐ下に出すようにしました。サイドバーで押したメモは新しいタブで開くようになり、前の「仮のタブ」は設定で選べます。

v0.9.0 のデータと同期先は、そのまま使えます。データの形は変えていないので、v0.9.0・v0.8.3・v0.8.2・v0.8.1・v0.8.0・v0.7.0 のデバイスと同じ同期先で一緒に使えます。PC 版の v0.9.0 を入れている場合は、設定の「更新」から入れ替えられます。

## 入れ方

- Windows: `sedum-note_0.10.0_windows-x64-setup.exe` を開きます。署名していないので「Windows によって PC が保護されました」と出たら、「詳細情報」を押してから「実行」を押します。
- macOS: `sedum-note_0.10.0_macos-universal.dmg` を開き、Sedum Note を「アプリケーション」へ移します。Apple の公証を受けていないので、初めて開くときに止められます。「システム設定」の「プライバシーとセキュリティ」で「このまま開く」を押してください。
- Linux（Debian・Ubuntu）: `sudo apt install ./sedum-note_0.10.0_linux-amd64.deb` で入れます。
- Linux（Fedora など）: `sudo dnf install ./sedum-note_0.10.0_linux-x86_64.rpm` で入れます。
- Linux（入れずに使う）: `chmod +x sedum-note_0.10.0_linux-x86_64.AppImage` のあと、そのファイルを開きます。
- Android: `sedum-note_0.10.0_android-arm64.apk` を開きます。v0.9.0 の上に入れられます。
- Web 版: https://aida0710.github.io/sedum-note/ を開きます。

ファイルの SHA-256 は `SHA256SUMS` にあります。`latest.json` と `.app.tar.gz` は、アプリが自分を更新するときに使うファイルです。

使い方はドキュメントのサイト https://aida0710.github.io/sedum-note/docs/ にまとめています。

## 気を付けること

- PC の画面で、サイドバーで押したメモは、いつも新しいタブで開くようになりました。もう開いているメモを押したときは、そのタブに移ります。v0.9.0 までの「仮のタブ」（次に押したメモと入れ替わるタブ）を使うときは、設定の「一般」の「サイドバーで押したメモを仮のタブで開く」をオンにします。
- 「新しいメモ」のボタンの名前を「メモを作成」にしました。サイドバーのボタン、スマホの「＋」、データベース表示、キーボードショートカットの名前、Android のウィジェットとショートカットが変わります。
- ライトのテーマの背景・サイドバー・線・タグの色を、わずかに青みのあるグレーにしました。自分で作ったテーマの色は変わりません。

## 足したもの

- 設定の「一般」の表示の欄に「サイドバーで押したメモを仮のタブで開く」を足しました（PC の画面だけ）。最初はオフです。
- スマホのメモの一覧が空のときに、「メモを作成」のボタンを出します。お気に入り・テンプレート・ゴミ箱の一覧では、それぞれに合った案内を出します。
- 検索で当たるメモが無いときは、探した言葉をタイトルにしてメモを作れます（スマホの検索と、PC のサイドバーの検索）。

## 変えたもの

- メモの上のプロパティを、外の枠で囲まずに、名前と値の行だけで並べるようにしました。値の欄の枠は残っています。
- スマホの書式のツールバーと上のバーのボタンを、44px おきに並べました。
- パスフレーズの 4 つの画面、暗号化キー、自動ロックの時間、ゴミ箱の日数、ショートカットのキーで、入力の誤りを欄のすぐ下に出します。送ってから分かった誤りは、その欄へ移って文字を選ぶので、すぐ打ち直せます。
- 選択範囲とカーソルの色を、テーマの accent の色から作るようにしました。
- メモの一覧のプレビューと検索の抜粋で、項目の期限の印（`📅 2026-11-19 09:00` の形）を「11月19日 09:00」の書き方で出します。
- 開閉する行の「▶」を、ほかの所と同じ山形のアイコンにしました。
- スマホの「＋」のボタンの青い影を、灰色の影にしました。

## 直したもの

- 指で操作する端末（スマホなど）で、並んだボタンの右端を押すと、右隣のボタンが反応していました（書式のツールバー、上のバー、メモの中の検索、表の色の選択）。
- 指で操作する端末で、小さいボタン、高さ 32px の文字のボタン、開閉の行、同期の状態、チェックリストのチェック、スイッチの押せる範囲を、見た目を変えずに 44px まで広げました。
- 文字に使う accent・danger・ok の色が、背景によってはコントラスト比 4.5:1 に届いていませんでした。どの背景の上でも 4.5:1 になる色にしました。
- プレースホルダーと「/」のメニューのキーの表示が薄く、読みにくくなっていました。「本文を書く…」のプレースホルダーは、ライトのテーマで 2.5:1 から 5.7:1 になりました。
- 指で操作する端末でいつも出している、見出しの折りたたみとズームの印を、3:1 まで濃くしました。
