書く・探す・整理する機能を大きく足しました。数式・図・手書き・段組みなどのブロック、ブロックへのリンクと埋め込み、アウトライン表示、表の編集、コマンドパレット、ノートブックのデータベース表示、期限と通知、スペース、WebDAV での同期、アプリ内の AI、プラグインが入っています。

v0.4.0 のデータと同期先は、そのまま使えます。PC 版の v0.4.0 を入れている場合は、「設定」の「更新」から入れ替えられます。同期しているデバイスは、全部を v0.5.0 に上げてください（「気を付けること」の 1 つ目）。

## 入れ方

- Windows: `sedum-note_0.5.0_windows-x64-setup.exe` を開きます。署名していないので「Windows によって PC が保護されました」と出たら、「詳細情報」を押してから「実行」を押します。
- macOS: `sedum-note_0.5.0_macos-universal.dmg` を開き、Sedum Note を「アプリケーション」へ移します。Apple の公証を受けていないので、初めて開くときに止められます。「システム設定」の「プライバシーとセキュリティ」で「このまま開く」を押してください。
- Linux（Debian・Ubuntu）: `sudo apt install ./sedum-note_0.5.0_linux-amd64.deb` で入れます。
- Linux（Fedora など）: `sudo dnf install ./sedum-note_0.5.0_linux-x86_64.rpm` で入れます。
- Linux（入れずに使う）: `chmod +x sedum-note_0.5.0_linux-x86_64.AppImage` のあと、そのファイルを開きます。
- Android: `sedum-note_0.5.0_android-arm64.apk` を開きます。v0.4.0 の上に入れられます。
- Web 版: https://aida0710.github.io/sedum-note/ を開きます。

ファイルの SHA-256 は `SHA256SUMS` にあります。`latest.json` と `.app.tar.gz` は、アプリが自分を更新するときに使うファイルです。

## 気を付けること

- v0.5.0 のデバイスが一度同期すると、同じ同期先を使う v0.4.0 のデバイスは「新しいバージョンのアプリで書かれています」と出して、更新するまで同期を止めます。古いアプリが新しい書式を本文から消し、その削除が同期で広がるのを防ぐためです。Web 版は、このリリースを出した時点で v0.5.0 に変わります。Web 版で同期している場合は、Web 版を開いて同期した時点で、ほかの v0.4.0 のデバイスが止まります。
- v0.5.0 で書き出したバックアップは、v0.4.0 では戻せません。
- アプリ内の AI を使うと、添えたメモの本文と選択した文字は、暗号化されない形でつなぎ先（Claude の API、OpenAI 互換のエンドポイント）へ送られます。ローカルの LLM をつなぎ先にすれば、このマシンの外へは出ません。既定はオフです。
- Windows は、インストーラーで入れずに置いただけの exe からの通知を、画面に出しません。期限の通知を使うときは、インストーラーで入れてください。
- Android のアプリに、録音のためのマイクの権限と、期限の通知のための通知の権限を足しました。マイクは初めて録音するとき、通知は「期限の通知」を入れるときに、Android が許可を聞きます。
- Web 版で WebDAV のサーバーを同期先にするには、サーバーに CORS の設定が要ります。アプリ（Windows・macOS・Linux・Android）は要りません。
- スペースの名前は、このデバイスの中に暗号化せずに置きます（同期先には送りません）。

## 足したもの

### 本文
- Markdown の文字を貼り付けると、見出し・リスト・表・コードなどの書式になります。
- 見出しを 6 段まで使えます。「/」から今日の日付と今の日時を入れられ、メモの文字数も出ます。
- 選んだ文字にハイライトと文字色を付けられます。
- 数式（LaTeX）、図（Mermaid）、段組み（2 段か 3 段）、脚注、コールアウト（色付きの囲み）を入れられます。
- 動画と Web ページを URL で埋め込めます。メモを開いただけでは外へつながず、「読み込む」を押したときに初めて読み込みます。
- 手書きの線と図形（直線・四角・円）を描ける枠を入れられます（「/」の「手書き・図形」）。
- 書類を撮って、傾きを直した画像として貼れます（「/」の「書類のスキャン」）。文字の読み取りはしません。
- アプリの中で録音して添付でき、添付した音声はその場で再生できます。添付した PDF は、メモの中でプレビューを開いて読めます。
- 子の項目を持つ箇条書きと、見出しを折りたためます。箇条書きの項目と見出しのセクションにズームでき、その項目と子だけが出ます。
- メモごとに、アウトライン表示（アウトライナー型のメモ）を選べます（メモの「…」の「アウトライン表示にする」）。
- PC の画面では、ブロックの左に出る持ち手をドラッグして、ブロックを並べ替えられます。
- メモの中のブロック（段落、見出し、箇条書きの項目）へリンクでき、ほかのメモのブロックを本文に埋め込めます。リンクと埋め込みには、元のブロックの今の中身が出ます。
- クエリのブロックを置くと、条件（ノートブック、タグ、含まれる言葉、プロパティの値）に合うメモの一覧が本文の中に出ます。
- PC の画面では、本文の列を左寄せ・中央・右寄せのどこに置くかを、メモごとに選べます。

### 表
- 列の幅の変更、セルの結合、ヘッダー行とヘッダー列の切り替え、上下左右への挿入、列ごとの文字の揃え方を足しました。
- 行と列を隣と入れ替える、列の値で行をソートする、列に含まれる言葉で行をフィルターする、ができます。セルには背景色を付けられます。

### 探す・つなぐ
- コマンドパレット（Ctrl+K）で、メモ（題と本文）・ノートブック・タグ・設定の項目・操作をまとめて探せます。打った言葉と同じ題のメモが無ければ、その言葉を題にして新しいメモを作れます。
- メモの中の検索（Ctrl+F）で、大文字と小文字の区別、単語単位、正規表現を切り替えられ、置換もできます（Ctrl+R）。
- メモ全体の検索を、`#タグ` と `notebook:名前` で絞り込めます。検索に名前を付けて保存すると、左の列から同じ検索を開けます。
- メモへのリンクにポインターを乗せると、リンク先の題と本文の最初の部分が出ます。左の列のメモを本文へドラッグすると、そのメモへのリンクが入ります。
- リンクされたメモの下に、リンクしているメモの一覧（バックリンク）と、題を文字のまま書いているメモ（リンクしていない言及）が出ます。言及は「リンクにする」でリンクに置き換えられます。
- PC の画面の「グラフ表示」で、メモ同士のリンクのつながりを図で見られます。

### 整理
- ノートブックごとに、メモのプロパティ（文字・数・日付・選択肢・チェック）を決められます。PC の画面では、ノートブックの「データベース表示」で、メモをテーブルかボードで見られます。
- メモとチェックリストの項目に期限を付けられます。期限のあるものは期限の一覧（Ctrl+Alt+E）に並びます。「設定」の「期限の通知」を入れると、期限が来たときに OS の通知で知らせます。Windows と Mac のアプリは、ウィンドウを閉じても終了せず、通知の領域（Mac はメニューバー）に残るようにできます。
- デイリーノート（今日の日付を題にしたメモ）を、ボタンかショートカットで開けます。
- メモの複製と結合、HTML とテキストでの書き出しを足しました。
- スペースで、メモの保管先を分けて切り替えて使えます（「設定」の「スペース」）。スペースごとに、手元の保存・同期先・暗号化キーが別になります。パスフレーズは、そのデバイスの全部のスペースで同じです。

### 画面
- 設定をページに分け、左の列の下に設定の歯車を置きました。
- タブは、右クリックのメニュー、ピン留め、閉じたタブを開き直す操作（Ctrl+Alt+Shift+T）、開いているタブの一覧を足しました。切り替えて戻ると、本文のスクロール位置とカーソルの位置が元に戻ります。
- 左の列のメモを、Ctrl（Mac では Command）か Shift を押しながら押して複数選び、まとめて移したりゴミ箱に入れたりできます。左の列は、↑↓ で行を移り、→← で一覧を開け閉めできます。
- PC の画面で、2 つのメモを左右に並べて開けます（「右に並べて開く」）。メモを別のウィンドウで開け、PC のアプリではウィンドウを最前面に固定できます。
- PC の画面に、本文だけにするフォーカスモードと、打っている行を中央に保つタイプライターモードを足しました。
- 自分で書いた CSS（カスタム CSS）で、画面の見た目を変えられます。
- スマホの一覧で、メモを右へ払うとピン留めを付け外しし、左へ払うとゴミ箱に入れます。一覧をいちばん上から下へ引いて離すと同期します。
- Ctrl+L（Mac は Command+L）か「設定」の「ロック」で、アプリをその場でロックできます。

### 同期
- WebDAV のサーバーも同期先にできます。同期先の入力欄の「同期先の種類」で、「S3 互換ストレージ」か「WebDAV」を選びます。
- メモの履歴を暗号化して同期先にも置くので、ほかのデバイスで残した版も見られます（履歴を開いたときに取ってきます）。

### AI とプラグイン
- アプリ内の AI とチャットして、メモについて質問したり、要約や書き直しを頼んだりできます（メモの「…」の「AI チャット」か Ctrl+Alt+A）。つなぎ先は、Claude の API か、OpenAI 互換のエンドポイント（Ollama などのローカルの LLM、OpenAI の API）から選び、「設定」の「AI」で有効にします。
- プラグインで、メモの「…」のメニューにコマンドを足せます。「設定」の「プラグイン」に GitHub のリポジトリを入れて取り込みます。プラグインは外の関数を何も使えない WebAssembly として動き、通信も保存も、ほかのメモを読むこともできません。見本は `aida0710/sedum-note/plugins/text-tools` です。形式は [docs/plugins.md](https://github.com/aida0710/sedum-note/blob/v0.5.0/docs/plugins.md) にあります。

## 確かめた環境

- Web 版: Chromium と WebKit で、画面の試験を通しました。v0.4.0 の Web 版で作ったデータ（同期・添付・履歴あり）を、v0.5.0 で開いて書き足し、同期できることを Chromium で確かめました。そのとき、同じ同期先の v0.4.0 のデバイスが同期を止めることも確かめています。
- Android 16（エミュレーター）: ブロックのリンクと埋め込み、AI チャットの画面、録音の許可、期限の通知（アプリを裏に回したまま出ること）を、デバッグ版で確かめました。配布用の APK と実機では確かめていません。録った音が聞こえるかも確かめていません。
- Linux: アプリ（deb）で、別のウィンドウ、ウィンドウの間で編集とロックが伝わること、最前面の固定、WebDAV での同期、GitHub からのプラグインの取り込みと実行を確かめました。
- Windows 11（仮想マシン）: 期限の通知、ウィンドウを閉じたあとも動かしたままにする機能（閉じている間の通知と、通知の領域のアイコン）、メモを別のウィンドウで開くことと最前面の固定、GitHub からのプラグインの取り込みと実行、WebDAV での同期を確かめました。スペースと、ウィンドウの間で編集が伝わることは確かめていません。
- macOS: 組み立てと、起動して最初の画面が出るところまでです。v0.5.0 で足した機能は、macOS では確かめていません。
- WebDAV のサーバーは、Apache と Nextcloud で確かめました。Web 版から本物の WebDAV のサーバーへの同期は確かめていません。
- アプリ内の AI は、決まった答えを返す偽の応答で確かめました。Claude の API とローカルの LLM への実際の呼び出しは確かめていません。
- iPhone の Safari は確かめていません。
