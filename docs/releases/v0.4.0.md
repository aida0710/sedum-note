2 台目からの同期の設定を、QR かファイルで渡せるようにしました。同期先を手で入力しなくて済みます。

v0.3.0 のデータと同期先は、そのまま使えます。PC 版の v0.3.0 を入れている場合は、「設定」の「更新」から入れ替えられます。v0.2 までの同期先から移る場合は、[v0.3.0 のリリースノート](https://github.com/aida0710/sedum-note/releases/tag/v0.3.0)の「v0.2 から移る」を見てください。

## 入れ方

- Windows: `sedum-note_0.4.0_windows-x64-setup.exe` を開きます。署名していないので「Windows によって PC が保護されました」と出たら、「詳細情報」を押してから「実行」を押します。
- macOS: `sedum-note_0.4.0_macos-universal.dmg` を開き、Sedum Note を「アプリケーション」へ移します。Apple の公証を受けていないので、初めて開くときに止められます。「システム設定」の「プライバシーとセキュリティ」で「このまま開く」を押してください。
- Linux（Debian・Ubuntu）: `sudo apt install ./sedum-note_0.4.0_linux-amd64.deb` で入れます。
- Linux（Fedora など）: `sudo dnf install ./sedum-note_0.4.0_linux-x86_64.rpm` で入れます。
- Linux（入れずに使う）: `chmod +x sedum-note_0.4.0_linux-x86_64.AppImage` のあと、そのファイルを開きます。
- Android: `sedum-note_0.4.0_android-arm64.apk` を開きます。v0.3.0 の上に入れられます。
- Web 版: https://aida0710.github.io/sedum-note/ を開きます。

ファイルの SHA-256 は `SHA256SUMS` にあります。`latest.json` と `.app.tar.gz` は、アプリが自分を更新するときに使うファイルです。

## 足したもの

- 同期の設定の書き出し: 参加済みのデバイスの「設定」→「同期」→「同期の設定を書き出す」で、QR が出て、ファイルにも保存できます。書き出すときに入力するものはありません。
- 同期の設定の取り込み: 加えるデバイスの最初の画面で「ほかのデバイスと同期する」を選び、カメラで QR を読むか、QR の画像か、保存したファイルを選びます。暗号化キーを入れると、同期先が入って接続の確認まで進みます。あとは、そのデバイスのパスフレーズを決めて「参加」を押します。
- Android のアプリに、カメラの権限を足しました。QR を読むために使い、初めて使うときに Android が許可を聞きます。

## 気を付けること

- 書き出した QR とファイルは、暗号化キーが無いと読めません。中には、暗号化した同期先のアクセスキーが入っています。暗号化キーを自分で短く決めた場合は、時間をかけて試されるおそれがあるので、ファイルを人に渡さないでください。
- Android のアプリがカメラの権限を持つようになったので、本文の「カメラで撮る」も、許可する前は先に許可を聞きます。
- カメラを使えないとき（許可しなかった、カメラの無い PC）は、QR の画像か、設定のファイルで取り込めます。

## 確かめた環境

- Web 版: Chromium と WebKit で、画面の試験を通しました。カメラをかざして読む流れは、Chromium で確かめています。
- Android 16（エミュレーター）: 配布用と同じ作りの APK で、カメラの許可の確認から、QR の読み取り、参加までを確かめました。カメラには QR の画像を写しています。実機のカメラでは確かめていません。
- Windows・macOS: 組み立てと、macOS で起動して最初の画面が出るところまでです。アプリのカメラは確かめていません。
- Linux: 組み立てと、起動して最初の画面が出るところまでです。Linux のアプリはカメラを扱えない見込みで、その場合は QR の画像かファイルで取り込みます。
- iPhone の Safari は確かめていません。
