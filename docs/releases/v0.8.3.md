アプリのアイコンを新しい絵にし、設定に「このアプリについて」のページを足しました。

v0.8.2 のデータと同期先は、そのまま使えます。データの形は変えていないので、v0.8.2・v0.8.1・v0.8.0・v0.7.0 のデバイスと同じ同期先で一緒に使えます。PC 版の v0.8.2 を入れている場合は、設定の「更新」から入れ替えられます。

## 入れ方

- Windows: `sedum-note_0.8.3_windows-x64-setup.exe` を開きます。署名していないので「Windows によって PC が保護されました」と出たら、「詳細情報」を押してから「実行」を押します。
- macOS: `sedum-note_0.8.3_macos-universal.dmg` を開き、Sedum Note を「アプリケーション」へ移します。Apple の公証を受けていないので、初めて開くときに止められます。「システム設定」の「プライバシーとセキュリティ」で「このまま開く」を押してください。
- Linux（Debian・Ubuntu）: `sudo apt install ./sedum-note_0.8.3_linux-amd64.deb` で入れます。
- Linux（Fedora など）: `sudo dnf install ./sedum-note_0.8.3_linux-x86_64.rpm` で入れます。
- Linux（入れずに使う）: `chmod +x sedum-note_0.8.3_linux-x86_64.AppImage` のあと、そのファイルを開きます。
- Android: `sedum-note_0.8.3_android-arm64.apk` を開きます。v0.8.2 の上に入れられます。
- Web 版: https://aida0710.github.io/sedum-note/ を開きます。

ファイルの SHA-256 は `SHA256SUMS` にあります。`latest.json` と `.app.tar.gz` は、アプリが自分を更新するときに使うファイルです。

## 足したもの

- アプリのアイコンを、霧の中のブランコの絵にしました。最初の画面とロックの画面のアイコン、Web 版のタブのアイコンも同じ絵です。
- 設定に「このアプリについて」のページを足しました。アイコンの元の絵（切り抜く前のもの）と作者、版、ライセンスを出し、次のボタンを置きました。
  - 「ライセンス」: Sedum Note のライセンス（Apache License 2.0）の全文、絵のライセンス、アプリに入っているオープンソースのソフトウェア 807 件の名前・版・ライセンスの文・ソースコードの置き場所。名前かライセンスで絞り込めます。
  - 「データの扱い」: 集めていない情報、保存と暗号化、同期、AI の機能、そのほかの通信、保証について。暗号化せずに残るもの（書き出した Markdown、Android で期限の通知を予約したときにメモの題と項目の文を OS に渡すこと、表示の設定）も書いています。
  - ソースコードを見るボタンと、不具合を報告するボタン（GitHub の Issues）。
  - 無保証であることと、「データ」のページのバックアップへ移るボタン。

- Windows・macOS・Linux・Android: 組み立てまでです。新しいアイコンと「このアプリについて」は、アプリと実機では確認していません。
