アプリ内の AI に開いているメモを直してもらえるようにし、AI の設定とチャットを作り直しました。履歴の戻し方、ノートブックの選び方、テンプレートの変数、画面の細かい使い勝手も直しています。

v0.5.0 のデータと同期先は、そのまま使えます。PC 版の v0.5.0 を入れている場合は、「設定」の「更新」から入れ替えられます。同期しているデバイスは、全部を v0.6.0 に上げてください（「気を付けること」の 1 つ目）。

## 入れ方

- Windows: `sedum-note_0.6.0_windows-x64-setup.exe` を開きます。署名していないので「Windows によって PC が保護されました」と出たら、「詳細情報」を押してから「実行」を押します。
- macOS: `sedum-note_0.6.0_macos-universal.dmg` を開き、Sedum Note を「アプリケーション」へ移します。Apple の公証を受けていないので、初めて開くときに止められます。「システム設定」の「プライバシーとセキュリティ」で「このまま開く」を押してください。
- Linux（Debian・Ubuntu）: `sudo apt install ./sedum-note_0.6.0_linux-amd64.deb` で入れます。
- Linux（Fedora など）: `sudo dnf install ./sedum-note_0.6.0_linux-x86_64.rpm` で入れます。
- Linux（入れずに使う）: `chmod +x sedum-note_0.6.0_linux-x86_64.AppImage` のあと、そのファイルを開きます。
- Android: `sedum-note_0.6.0_android-arm64.apk` を開きます。v0.5.0 の上に入れられます。
- Web 版: https://aida0710.github.io/sedum-note/ を開きます。

ファイルの SHA-256 は `SHA256SUMS` にあります。`latest.json` と `.app.tar.gz` は、アプリが自分を更新するときに使うファイルです。

## 気を付けること

- v0.6.0 のデバイスが一度同期すると、同じ同期先を使う v0.5.0 のデバイスは「新しいバージョンのアプリで書かれています」と出して、更新するまで同期を止めます。エディタと Yjs をつなぐ部品（`@tiptap/y-tiptap`）を上げたので、データの形の版を 13 から 14 に上げたためです。Web 版は、このリリースを出した時点で v0.6.0 に変わります。Web 版で同期している場合は、Web 版を開いて同期した時点で、ほかの v0.5.0 のデバイスが止まります。
- v0.6.0 で初めてロックを解除したときに、手元のメモを新しい形に移し替えます。前の部品がメモに書き足していた記録を消すだけで、メモの中身、更新日時、履歴は変わりません。
- v0.6.0 で書き出したバックアップは、v0.5.0 では戻せません。
- アプリ内の AI の会話を、このデバイスのこのスペースに暗号化して残すようになりました（新しい方から 50 件）。同期とバックアップには入りません。添えたメモの本文の写しは会話に残しませんが、選択して渡した文字と AI の答えは残ります。
- アプリ内の AI の「保存して確かめる」は、つなぎ先へモデルの一覧を問い合わせます。

## 足したもの

### アプリ内の AI
- API キー（とエンドポイント）を入れて「保存して確かめる」を押すと、つなぎ先からモデルの一覧を取ってきます。取れたときだけ保存し、モデルは一覧から選びます。モデル名の手入力はやめました。
- チャットの上でモデルを切り替えられます。答えを受け取っている間は、送るボタンが止めるボタンに変わります。
- チャットの上の「残した会話」から、前の会話を開いて続きを話せます。
- 開いているメモを添えて「このメモを直して」のように頼むと、AI が直しの案を出します。案は、消すブロックと足すブロックの差分で出て、「適用する」を押したときだけメモに入ります。入れ替えるのは変わったブロックだけで、直していないブロックの書式（文字色、段組みなど）はそのまま残ります。適用する前の状態は、メモの履歴に残ります。
- チャットの下の「直しの案を、承認を待たずに適用する」を入れると、案をすぐ適用します。

### メモ
- 履歴から戻すときは、コピーを作らずにそのメモを上書きします（「このバージョンに戻す」）。戻す前の状態は「復元の前」として履歴に残ります。アウトライン表示かどうかも、そのバージョンの値に戻ります。
- メモの「…」の「ノートブックを選ぶ」で、ダイアログからノートブックを選びます。名前で絞り込め、押すとその場で付け外しします。
- テンプレートの題と本文に `@date`・`@time`・`@datetime`・`@title` と書くと、テンプレートからメモを作るときや「/」で入れるときに、その時の値に置き換わります。日付の形式は、デイリーノートの題の形式に従います。

### 画面
- 左の列の「Sedum Note」の横のアイコンを、アプリのアイコンにしました。
- タブが多くても、開いたタブを見える所まで送ります。
- 左の列のテンプレートとゴミ箱を、すべてのメモ・お気に入り・期限の一覧と同じまとまりに移しました。
- 左の列の検索は、「ノートブックの中」と「すべてのメモ」を切り替えて探せます。結果の行には、本文の中で当たった所が、前後の文と一緒に出ます。
- メモの「…」のメニューを、まとまりごとに区切りました。書き出しは「書き出す」の 1 つにまとめ、ダイアログで形式を選びます。ショートカットのある項目には、キーを出します。
- コマンドパレット（Ctrl+K）を開いた直後に、最近のメモと、よく使う操作を並べます。
- データベース表示の表とボードから、新しいメモとプロパティを足せます。
- 設定の選択欄とチェックを、PC の広い画面では、名前を左・欄を右に置く 1 行の形にしました。
- スマホのメモの一覧に、ノートブックの色の印を出します。

## 確かめた環境

- Web 版: Chromium と WebKit で、画面の試験を通しました。v0.5.0 の Web 版で作ったデータ（同期・添付・履歴あり）を、v0.6.0 で開いて書き足し、同期できることを Chromium で確かめました。そのとき、同じ同期先の v0.5.0 のデバイスが同期を止めることも確かめています。
- アプリ内の AI は、決まった答えを返す偽の応答で確かめました。Claude の API と OpenAI 互換のサーバーへの実際の呼び出し（モデルの一覧、直しの案）は確かめていません。
- Windows・macOS・Linux・Android: 組み立てと、macOS で起動して最初の画面が出るところまでです。このリリースで足した機能は、アプリと実機では確かめていません。
- iPhone の Safari は確かめていません。
