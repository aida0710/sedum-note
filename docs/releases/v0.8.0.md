アプリ全体を見直し、使いにくい所と見た目の不ぞろいを直しました。キーボードショートカットを設定で変えられるようになり、左の列で押したメモは仮のタブで開きます。別のウィンドウはロックを共有し、操作しない時間が続いたら自動でロックすることもできます。

v0.7.0 のデータと同期先は、そのまま使えます。データの形は変えていないので、v0.7.0 のデバイスと同じ同期先で一緒に使えます。PC 版の v0.7.0 を入れている場合は、設定の「更新」から入れ替えられます。

## 入れ方

- Windows: `sedum-note_0.8.0_windows-x64-setup.exe` を開きます。署名していないので「Windows によって PC が保護されました」と出たら、「詳細情報」を押してから「実行」を押します。
- macOS: `sedum-note_0.8.0_macos-universal.dmg` を開き、Sedum Note を「アプリケーション」へ移します。Apple の公証を受けていないので、初めて開くときに止められます。「システム設定」の「プライバシーとセキュリティ」で「このまま開く」を押してください。
- Linux（Debian・Ubuntu）: `sudo apt install ./sedum-note_0.8.0_linux-amd64.deb` で入れます。
- Linux（Fedora など）: `sudo dnf install ./sedum-note_0.8.0_linux-x86_64.rpm` で入れます。
- Linux（入れずに使う）: `chmod +x sedum-note_0.8.0_linux-x86_64.AppImage` のあと、そのファイルを開きます。
- Android: `sedum-note_0.8.0_android-arm64.apk` を開きます。v0.7.0 の上に入れられます。
- Web 版: https://aida0710.github.io/sedum-note/ を開きます。

ファイルの SHA-256 は `SHA256SUMS` にあります。`latest.json` と `.app.tar.gz` は、アプリが自分を更新するときに使うファイルです。

## 気を付けること

- 左の列のメモを Ctrl+クリック（Mac は ⌘+クリック）すると、別のウィンドウで開くようになりました。メモをいくつか選ぶときは Shift+クリックを使います。
- PC のアプリと Web 版の期限の通知は、ロックを解除している間だけ出ます。自動でロックする時間を決めると、ウィンドウを閉じて常駐させている間もその時間でロックし、通知が止まります。
- 左の列でメモを押すと、題が斜体の仮のタブで開き、次に押したメモと入れ替わります。書き始めるか、タブをダブルクリックすると、ふつうのタブになります。
- デイリーノートの機能をなくしました。左の列のボタン、Ctrl+Alt+J、設定の「デイリーノート」はありません。今までに作ったデイリーノートは、ふつうのメモとして残ります。その日のメモが要るときは、題に @date を入れたテンプレートから作ってください。テンプレートの日付と時刻の形式は、設定の「一般」の「テンプレート」で選びます。デイリーノートの題の形式を変えていた場合も、この形式は既定（2026-11-14 の形）に戻るので、選び直してください。
- メモの下の「リンクしていない言及」をなくしました。リンクしているメモの一覧（バックリンク）は残っています。
- 画面の言葉をそろえました。「書き出す・取り込む」は「エクスポート・インポート」に、「消す・ゴミ箱に入れる・戻す」は「削除・ゴミ箱に移動・復元」に、「確かめる」は「確認」になっています。
- 設定で押してすぐ効く項目は、チェックボックスからスイッチに変えました。
- メモをノートブックへ移す、ピン留めする、お気に入りにするだけでは、更新日時が変わらなくなりました。「更新した順」の並びは、本文・題・期限・プロパティの値を変えたときだけ動きます。

## 足したもの

### ロック
- 別のウィンドウで開いたメモは、元のウィンドウのロックを解除していれば、パスフレーズを聞かずに開きます。ロックしたあとは、どれかのウィンドウで解除すれば、ロックの画面のままのほかのウィンドウも一緒に開きます。Web 版で解除が伝わるのは、メモを開いた別のウィンドウと元のウィンドウの間だけです。ほかのタブは、それぞれパスフレーズで解除します。
- 設定の「セキュリティ」の「操作が無いときに自動でロック」で、どのウィンドウでも操作が無いまま決めた時間が過ぎたら、自動でロックできます。15 分・45 分・1・3・6・12・24 時間から選ぶか、「時間を指定」で 1 分から 7 日までを分か時間の単位で入れます。既定は「しない」で、このデバイスだけの設定です。スリープしていた間も時間は進みます。

### キーボードとコマンドパレット
- 設定の「ショートカット」で、どこでも効くキー（17 個）と、本文・表の中のキー（13 個）を変えたり、なくしたりできます。変えたキーはこのデバイスだけに効きます。
- コマンドパレットから、開いているメモの名前の変更・複製・印刷・お気に入り・ピン留め・ゴミ箱への移動、タブのピン留めとほかのタブを閉じる操作、ノートブックの追加、スペースの切り替え、今すぐ同期を選べます。
- メニューは ↑↓・Home・End と、項目の名前の最初の文字で選べます。タブ、左の列、履歴の一覧、ノートブックやメモを選ぶダイアログも、キーボードだけで操作できます。

### 書く画面
- 「/」だけを打つと、最近使った 5 件と、まとまりごとに見出しを付けた候補が出ます。行頭で打てる書き方（# や - など）も添えています。
- 本文の Web のリンクを Ctrl+クリック（Mac は ⌘+クリック）で開けます。リンクの中にカーソルを置くと、URL を見て、開く・編集・解除ができる面が出ます。
- ズームに入るときと戻るときに、本文を短く動かして切り替わりを見せます。
- ブロックのメニューの「変換」に見出し 4〜6 を足しました。

### 検索
- 全角と半角、ひらがなとカタカナを区別せずに探します。「ABC」で「ＡＢＣ」に、「めも」で「メモ」に一致します。メモ全体の検索、メモの中の検索、コマンドパレット、選ぶダイアログ、表の行の絞り込みに効きます。
- 脚注にだけ書いた言葉でも、メモの検索で見つかります。

### 設定
- メモの並び順に、更新・作成が古い順と、タイトルの逆順（Z→A）を足しました。
- 設定の「同期」でも、同期の設定のファイルと QR コードをインポートできます。
- 設定の「更新」の「更新を確認する」で、いつでも新しいバージョンを確認できます。Web 版でも確認でき、新しいバージョンがあれば読み込み直して入れ替えます。
- 保存していない入力を残したまま設定のほかのページへ移るときは、捨ててよいかを確認します。

### スマホ
- 一覧・エディタ・設定の文字と、最初の画面・ロック・ダイアログ・通知の文字を大きくしました。
- 下のツールバーに、元に戻す・やり直すと、箇条書きのインデント・上下の移動を足しました。
- ノートブックを行の「…」から操作でき、入れ子のノートブックをインデントして並べます。保存した検索も開けます。
- メモから一覧へ戻ると、前に見ていた位置に戻ります。
- Android のアプリでは、チェック・スイッチ・スワイプと引っ張って同期のときに短く振動します。設定の「一般」の「操作したときに振動する」で止められます。

### 見た目と動き
- ダイアログと通知が、出るときと消えるときに短く動きます。動きを減らす設定にしていれば動きません。
- 本文のブロックの間と文字の大きさ、左の列の選んだ行、タブの見た目を変え、アイコンの線の太さと入力欄の角丸・高さをそろえました。暗いテーマでは、メニューとダイアログが浮いて見えるようにしました。
- どのテーマでも、薄い文字と色の付いた文字が読める濃さになるようにしました。
- 最初の画面とロックの画面に、アプリのアイコンと名前を出しました。
- バックアップ、Markdown のインポートとエクスポート、同期、添付など、数秒かかる処理に件数と進み具合の棒を出します。

## 直したもの

- WebKit（Safari）で、選んだ数式の上で文字を打つと、数式が消えていました。
- ほかのメモとの結合と、残した AI の会話の削除は、選んだ瞬間に行われて戻せませんでした。確認を出します。保存した検索を消したときと、メモをドラッグで別のノートブックへ移したときは、「元に戻す」を出します。
- 区切り線・数式の上で打った文字や、表のすぐ下の Backspace で、ブロックや表がまるごと消えていました。
- 別のウィンドウやタブを開いた直後にほかのウィンドウで書いた変更が、開いたウィンドウに出ないことがありました。
- プロパティを足すと、名前を決める前の仮の名前のまま記録に書かれていました。
- 「本文。#小説」のように、句読点のすぐ後ろの「#言葉」がタグになりませんでした。
- メモが多いとき、本文を打つたびに左の列が、コマンドパレットで打つたびにパレットが止まっていました。Markdown を 1,000 件インポートすると 2 分以上かかっていたのを、5 秒ほどにしました。
- 長い名前やタグで、ダイアログの見出し、本文の上のタグとプロパティ、表の見出し、左の列の行がはみ出していました。
- 中身の分からない失敗の通知に次にすることを添え、案内だけだった画面に行き先のボタンを置きました。

## 確認した環境

- Web 版: Chromium と WebKit で、画面の試験を通しました。v0.7.0 の Web 版で作ったデータ（同期・添付・履歴あり）を v0.8.0 で開けることと、同じ同期先の v0.7.0 のデバイスとの間で、互いの書き足しが届くことを Chromium で確認しました。
- Linux のアプリ: 別のウィンドウがパスフレーズを聞かずに開くことと、ロックと解除がウィンドウの間で伝わることを確認しました。
- Windows・macOS・Android: 組み立てと、macOS で起動して最初の画面が出るところまでです。このリリースで足した機能は、これらのアプリと実機では確認していません。
- Safari（Mac と iPhone）は確認していません。Mac の Safari で、⌘+クリックで開く別のウィンドウがポップアップとして止められないかも確かめていません。
