AI のクライアントからメモを操作できる窓口（MCP）を PC 版に足しました。「/」でブロックを選べるようにし、検索、テンプレート、目次なども足しています。スマホのブラウザで、キーボードを開くと書式のツールバーが隠れる不具合も直しました。

v0.2.0 のデータはそのまま使えます。PC 版の v0.2.0 を入れている場合は、「設定」の「更新」から入れ替えられます。

## 入れ方

- Windows: `sedum-note_0.2.1_windows-x64-setup.exe` を開きます。署名していないので「Windows によって PC が保護されました」と出たら、「詳細情報」を押してから「実行」を押します。
- macOS: `sedum-note_0.2.1_macos-universal.dmg` を開き、Sedum Note を「アプリケーション」へ移します。Apple の公証を受けていないので、初めて開くときに止められます。「システム設定」の「プライバシーとセキュリティ」で「このまま開く」を押してください。
- Linux（Debian・Ubuntu）: `sudo apt install ./sedum-note_0.2.1_linux-amd64.deb` で入れます。
- Linux（Fedora など）: `sudo dnf install ./sedum-note_0.2.1_linux-x86_64.rpm` で入れます。
- Linux（入れずに使う）: `chmod +x sedum-note_0.2.1_linux-x86_64.AppImage` のあと、そのファイルを開きます。
- Android: `sedum-note_0.2.1_android-arm64.apk` を開きます。v0.2.0 の上に入れられます。
- Web 版: https://aida0710.github.io/sedum-note/ を開きます。

ファイルの SHA-256 は `SHA256SUMS` にあります。`latest.json` と `.app.tar.gz` は、アプリが自分を更新するときに使うファイルです。

## 足したもの

- MCP（PC 版だけ）: MCP に対応した AI のクライアントから、メモの検索・読み取り・作成・追記・書き換え・ゴミ箱の操作と、ノートブックの操作ができます。既定はオフで、「設定」の「MCP」で開きます。使えるのは、アプリのロックを解除している間だけです。
- 「/」のメニュー: 本文で「/」を打つと、見出し・リスト・表・画像などのブロックを選べます。
- 検索: メモの中を検索でき（Ctrl+F）、当たった所に色が付きます。ノートブックやタグを開いているときは、まずその中を探します。
- キーボードショートカット（PC の画面）: 新しいメモ、検索、タブの切り替えなど。一覧は「設定」にあります。
- テンプレート: メモをテンプレートにすると、そこから新しいメモを作れます。「/」からは、テンプレートの本文をその場に入れられます。
- 目次: 本文の見出しを並べ、押すとその見出しへ移ります。
- 写真の縮小: 貼るときに、長い辺を 2048px まで縮められます。既定は元のままで、「設定」で変えます。
- 印刷・PDF での保存: メモの「…」から。Android のアプリにはありません。
- ノートブックの色とアイコン（PC の画面で選びます）。
- ゴミ箱の自動削除: 決めた日数がたったメモを完全に削除します。既定は削除しません。
- Android: カメラでその場で撮って貼れます。ホーム画面のウィジェットとアイコンの長押しから、新しいメモを開けます。

## 直したもの

- Web 版をスマホのブラウザで開くと、キーボードを開いたときに書式のツールバーが隠れていました。
- Android で暗いテーマを選ぶと、ステータスバーの所だけ白く残っていました。
- スマホで、リンクから別のメモを開いたあとの「戻る」が、一覧に戻りませんでした。
- メモが多いとき、同期のたびに手元の暗号文を全部読んでいたのをやめました。

## 気を付けること

- MCP で AI が読んだメモは、暗号化されない形で AI の提供元へ送られます。
- MCP が対応しているのは、仕様 2026-07-28 の HTTP です。それより前の手順でつなぐクライアントからはつながりません。Claude Code 2.1 でつながることを確かめています。
- ゴミ箱の自動削除をオンにすると、そのデバイスが消したメモは、ほかのデバイスからも消えます。完全に削除したメモは元に戻せません。
- テンプレートとノートブックの色・アイコンは同期します。v0.2.0 のアプリでは、テンプレートはふつうのメモとして見え、色とアイコンは出ません。

## 確かめた環境

- Web 版: Chromium と WebKit で、足した機能の画面の試験を通しました。スマホのブラウザのキーボードは、Android の Chrome で確かめました。iPhone の Safari は確かめていません。
- Linux: 組み立てたアプリに、Claude Code と公式の MCP のクライアントをつなぎました。AppImage は、古いバージョンから入れ替える更新を確かめています。
- Android 16（エミュレーター）: 配布用と同じ作りの APK で、共有、新しいメモのショートカット、カメラを確かめました。ウィジェットをホーム画面に置く操作と、実機は確かめていません。
- Windows・macOS: 組み立てと、macOS で起動して最初の画面が出るところまでです。MCP と印刷は、Windows と macOS ではまだ確かめていません。
