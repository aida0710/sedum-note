メモを入れるノートブックを 1 つにし、どのノートブックにも入れていないメモを「未指定」に並べるようにしました。履歴は書くのを止めたところで区切って残し、AI チャット・MCP・プラグインが本文を変えた前と後を、別のバージョンとして残します。AI チャットの答えは Markdown として表示します。使い方のドキュメントのサイトも作りました。

v0.8.3 のデータと同期先は、そのまま使えます。データの形は変えていないので、v0.8.3・v0.8.2・v0.8.1・v0.8.0・v0.7.0 のデバイスと同じ同期先で一緒に使えます。PC 版の v0.8.3 を入れている場合は、設定の「更新」から入れ替えられます。

## 入れ方

- Windows: `sedum-note_0.9.0_windows-x64-setup.exe` を開きます。署名していないので「Windows によって PC が保護されました」と出たら、「詳細情報」を押してから「実行」を押します。
- macOS: `sedum-note_0.9.0_macos-universal.dmg` を開き、Sedum Note を「アプリケーション」へ移します。Apple の公証を受けていないので、初めて開くときに止められます。「システム設定」の「プライバシーとセキュリティ」で「このまま開く」を押してください。
- Linux（Debian・Ubuntu）: `sudo apt install ./sedum-note_0.9.0_linux-amd64.deb` で入れます。
- Linux（Fedora など）: `sudo dnf install ./sedum-note_0.9.0_linux-x86_64.rpm` で入れます。
- Linux（入れずに使う）: `chmod +x sedum-note_0.9.0_linux-x86_64.AppImage` のあと、そのファイルを開きます。
- Android: `sedum-note_0.9.0_android-arm64.apk` を開きます。v0.8.3 の上に入れられます。
- Web 版: https://aida0710.github.io/sedum-note/ を開きます。

ファイルの SHA-256 は `SHA256SUMS` にあります。`latest.json` と `.app.tar.gz` は、アプリが自分を更新するときに使うファイルです。

使い方はドキュメントのサイト https://aida0710.github.io/sedum-note/docs/ にまとめました。

## 気を付けること

- メモを入れられるノートブックは 1 つになりました。v0.8.3 までに 2 つ以上のノートブックに入れたメモは、あとに入れた方の 1 つに入っているものとして表示します。別のノートブックへ移すと、ほかのノートブックからも外れます。
- メモの「…」の「ノートブックを選択」は、「ノートブックへ移動」になりました。ノートブックを 1 つ選ぶと、メモを移してダイアログを閉じます。一覧の最後の「未指定」を選ぶと、ノートブックから出します。
- ノートブックを削除すると、中のメモとノートブックは 1 つ上の階層へ移ります。一番上の階層のノートブックなら、メモは「未指定」へ移ります。
- 検索の `notebook:名前` はそのノートブックの中のノートブックに入れたメモにも当たります。
- 履歴は 10 分おきに残すのをやめました。書くのを 3 分以上止めてからまた書き始めたときに、止める前の状態を残します。続けて書いている間は 1 つのバージョンにまとまります。1 件のメモに残す数は、50 件から 200 件にしました。
- AI チャットと MCP のツールで、メモを入れるノートブックを指定する引数を `notebookIds`（一覧）から `notebookId`（1 つ。`null` で「未指定」）に変えました。

## 足したもの

### ノートブック

- どのノートブックにも入れていないメモは、左の列とスマホのノートブックの一覧の最後にある「未指定」に並びます。メモを「未指定」へドラッグすると、ノートブックから出せます。
- ほかのデバイスで削除したノートブックに、同時に入れたメモは、同期のときに「未指定」へ移します。

### 履歴

- AI チャット・MCP・プラグインが本文を変えるときは、変える前の自分の書きかけと変えた結果を、間隔に関わらず別のバージョンとして残します。追記と、プラグインによる選択の入れ替えでも残します。
- バージョンの名前は、その状態を作ったものに合わせて「自分の編集」「AIチャットの編集」「MCPの編集」「プラグインの編集」と出します。v0.8.3 までに残した、AI などが変える前のバージョンは、今までどおり「置き換え前（AI・MCP・プラグイン）」と出します。
- 題と本文が直前のバージョンと同じなら、バージョンを増やしません。
- 履歴を開くときに、まだ保存していない入力を先に保存します。

### AI チャット

- 答えを Markdown として表示します。見出し・太字・斜体・取り消し線・コード・表・箇条書き・チェックリスト・引用・リンクを出します。
- 答えの中の HTML のタグは文字のまま出し、画像は読み込まずに説明の文をリンクにします。外のブラウザで開くリンクは、Web のページとメールだけです。
- 答えのコピーと、メモに入れるボタンは、今までどおり Markdown の文を使います。

### ドキュメント

- 使い方のドキュメントのサイト（https://aida0710.github.io/sedum-note/docs/ ）を作りました。機能ごとのページに、アプリの画面の画像を載せています。README は概要・主な機能・インストール・開発・ライセンスだけの短い形にしました。

## 直したもの

- スマホでメニューを開いたまま端末の「戻る」を押すと、下のメモまで閉じていました。今はメニューだけを閉じます。
- Markdown の表を貼り付けたとき、区切りの行の `-` が 1〜2 個（`|:-|-:|` など）だと、表にならずに文のまま貼り付いていました。
