写真を貼ったメモと長いメモで打つときの重さを減らし、完全に削除したメモが戻ることがある不具合を直しました。

v0.8.1 のデータと同期先は、そのまま使えます。データの形は変えていないので、v0.8.1・v0.8.0・v0.7.0 のデバイスと同じ同期先で一緒に使えます。PC 版の v0.8.1 を入れている場合は、設定の「更新」から入れ替えられます。

## 入れ方

- Windows: `sedum-note_0.8.2_windows-x64-setup.exe` を開きます。署名していないので「Windows によって PC が保護されました」と出たら、「詳細情報」を押してから「実行」を押します。
- macOS: `sedum-note_0.8.2_macos-universal.dmg` を開き、Sedum Note を「アプリケーション」へ移します。Apple の公証を受けていないので、初めて開くときに止められます。「システム設定」の「プライバシーとセキュリティ」で「このまま開く」を押してください。
- Linux（Debian・Ubuntu）: `sudo apt install ./sedum-note_0.8.2_linux-amd64.deb` で入れます。
- Linux（Fedora など）: `sudo dnf install ./sedum-note_0.8.2_linux-x86_64.rpm` で入れます。
- Linux（入れずに使う）: `chmod +x sedum-note_0.8.2_linux-x86_64.AppImage` のあと、そのファイルを開きます。
- Android: `sedum-note_0.8.2_android-arm64.apk` を開きます。v0.8.1 の上に入れられます。
- Web 版: https://aida0710.github.io/sedum-note/ を開きます。

ファイルの SHA-256 は `SHA256SUMS` にあります。`latest.json` と `.app.tar.gz` は、アプリが自分を更新するときに使うファイルです。

## 足したもの

- 設定の「一般」の、本文のテキストサイズ・文字間隔・行間のつまみの横に、その項目だけをデフォルトに戻すボタンを足しました。ボタンの名前に、戻る先の値（16px など）を出します。

## 直したもの

- 写真を貼ったメモで打つと、保存のたびに本文の写真・PDF・音声を全部読み込み直していて、重く、写真がちらついていました。写真の幅を変えたあとも同じでした。
- 長いメモで打つと、打つたびに本文全体の文字数を数え直していて、重くなっていました。変わった段落だけを数え直します。
- 左の列の一覧を作るたびに、検索していなくても、全部のメモの本文を検索用の形に変換していました。
- 完全に削除した直後にロックし、読み込み直すかアプリを開き直すと、削除が保存されておらず、メモがゴミ箱に戻ることがありました。
- PC でも、ロックの画面のカードを画面の縦の真ん中に置きます。
- 本文の幅より狭い写真では、幅を変える持ち手が写真の角でなく枠の端に出て、つかんだ所と写真の端がずれていました。持ち手は写真の右下の角に出ます。マウスでは、持ち手をつかめる範囲も広げました。

## 確認した環境

- Web 版: Chromium と WebKit で、画面の試験を通しました。Chromium では、v0.8.1 と打つときの重さを比べました。
- Windows・macOS・Linux・Android: 組み立てと、macOS と Linux で起動して最初の画面が出るところまでです。このリリースで直した所は、アプリと実機では確認していません。
