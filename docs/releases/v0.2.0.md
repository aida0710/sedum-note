アプリの名前を Sedum Note に変え、同期しなくても使えるようにしました。同時の編集は 1 つのメモにマージします。履歴、表、テーマ、Markdown の取り込みと書き出しなども足しました。

**v0.1.0（memo-app）のデータは引き継げません。** 保存の形式を変えたので、v0.1.0 のメモと同期先は、このバージョンでは開けません。必要なメモは v0.1.0 のアプリで開いて写してください。同期先は新しいバケットか、別のフォルダを使ってください。Windows と Android では、v0.1.0 とは別のアプリとして入ります。

## 入れ方

- Windows: `sedum-note_0.2.0_windows-x64-setup.exe` を開きます。署名していないので「Windows によって PC が保護されました」と出たら、「詳細情報」を押してから「実行」を押します。
- macOS: `sedum-note_0.2.0_macos-universal.dmg` を開き、Sedum Note を「アプリケーション」へ移します。Apple の公証を受けていないので、初めて開くときに止められます。「システム設定」の「プライバシーとセキュリティ」で「このまま開く」を押してください。Apple シリコンと Intel のどちらの Mac でも動きます。
- Linux（Debian・Ubuntu）: `sudo apt install ./sedum-note_0.2.0_linux-amd64.deb` で入れます。
- Linux（Fedora など）: `sudo dnf install ./sedum-note_0.2.0_linux-x86_64.rpm` で入れます。
- Linux（入れずに使う）: `chmod +x sedum-note_0.2.0_linux-x86_64.AppImage` のあと、そのファイルを開きます。Ubuntu 24.04 以降で起動しないときは、`sudo apt install libfuse2t64` で FUSE を入れてください。
- Android: `sedum-note_0.2.0_android-arm64.apk` を開きます。ブラウザやファイルのアプリに「不明なアプリのインストール」を許可してください。64 ビットの ARM の端末向けです。
- Web 版: https://aida0710.github.io/sedum-note/ を開きます。インストールは要りません。

ファイルの SHA-256 は `SHA256SUMS` にあります。`latest.json` と `.app.tar.gz` は、アプリが自分を更新するときに使うファイルです。

## 変わったこと

- 同期しなくても使えます: 最初の画面ではパスフレーズだけを決めます。同期はあとから「設定」で足せます。
- 同時の編集をマージします: 2 台で同じメモを同時に変えても、両方の変更が 1 つのメモに残ります。「（競合コピー）」のメモは作りません。
- ファイルを添付できます: 写真のほか、どの種類のファイルも 1 件 100 MB まで添付できます。添付も 1 件ずつ暗号化します。
- バックアップ: メモ・ノートブック・添付を、暗号化したまま 1 つのファイルに書き出せます。新しく入れたアプリの最初の画面の「バックアップから戻す」で戻せます。
- 履歴: メモの「…」から開けます。本文を編集し始める前の状態が約 10 分おきに残り、選んだ版を別のメモとして復元できます。履歴はそのデバイスだけに残り、同期とバックアップには入りません。
- 表、色付きのコード、メモ同士のリンク: リンクは、リンク先のタイトルを変えても表示がついてきます。
- Markdown の取り込みと書き出し: Markdown のファイル（.md）と、それをまとめた zip を取り込めます。書き出すと、ノートブックをフォルダにした zip になります。
- Android の共有: ほかのアプリの「共有」から文字・写真・ファイルを受け取り、新しいメモにします。
- テーマと表示: テーマは 6 種類から選べ、色を選んで自分のテーマも作れます。言語は日本語と英語です。メモの並び順と本文の文字の大きさも選べます。
- このデバイスのデータを消す: パスフレーズを忘れたときや、デバイスを手放すときに使えます（ロック解除の画面と「設定」）。同期先のメモは消えません。
- アプリの更新: デスクトップのアプリは、新しいバージョンを「設定」からダウンロードして入れ替えられます。Android のアプリは、新しいバージョンがあることを知らせます。

## 気を付けること

- パスフレーズを忘れると、どのデバイスからもメモを読めなくなります。運営者のいる仕組みではないので、取り戻す方法はありません。
- Markdown で書き出したファイルは暗号化されません。置き場所に気を付けてください。
- アプリは、ロックを解除したときに、新しいバージョンがあるかを GitHub へ確かめに行きます。送るのはアプリのバージョンと OS の種類だけです。「設定」の「更新」で止められます。
- アプリが自分を更新できるのは、このバージョンの次のバージョンが出てからです。入れ替える前に、配布元の署名を確かめます。
- この先、新しい書式が入ったバージョンを 1 台に入れて同期すると、ほかのデバイスは、アプリを更新するまで同期を止めて更新を求めます。古いアプリが知らない書式を本文から消さないようにするためです。
- テーマ・言語などの表示の設定と履歴は、デバイスごとです。同期しません。

## 確かめた環境

- Web 版: Chromium と WebKit で、2 台の間の同期、表の同時の編集、履歴、Markdown の書き出しと取り込み、バックアップ、テーマ、データの消去を確かめました。
- Android 16（エミュレーター）: 配布用と同じ作りの APK（エミュレーターに合わせた x86_64）で、共有からの受け取りと、テーマの色がステータスバーの所にも当たることを確かめました。同期と添付の保存は、1 つ前の作りのデバッグ版で確かめています。実機ではまだ確かめていません。
- Linux: AppImage を起動して最初の画面が出ることと、古いバージョンから AppImage を入れ替える更新を確かめました。deb と rpm での更新はまだ確かめていません。
- Windows・macOS: 組み立てと、macOS で起動して最初の画面が出るところまでです。このバージョンのメモの操作・同期・更新は、Windows と macOS ではまだ確かめていません。
