アプリ内の AI がメモ全体を探して読み、作って直せるようになりました。書く画面も作り直し、書式のボタンは文字を選んだときだけ出す形にしました。ブロックのメニュー、ズーム、写真の大きさの変更、日本語入力のままの箇条書きも足しています。

v0.6.0 のデータと同期先は、そのまま使えます。PC 版の v0.6.0 を入れている場合は、「設定」の「更新」から入れ替えられます。同期しているデバイスは全部を v0.7.0 に上げてください（「気を付けること」の 1 つ目）。

## 入れ方

- Windows: `sedum-note_0.7.0_windows-x64-setup.exe` を開きます。署名していないので「Windows によって PC が保護されました」と出たら、「詳細情報」を押してから「実行」を押します。
- macOS: `sedum-note_0.7.0_macos-universal.dmg` を開き、Sedum Note を「アプリケーション」へ移します。Apple の公証を受けていないので、初めて開くときに止められます。「システム設定」の「プライバシーとセキュリティ」で「このまま開く」を押してください。
- Linux（Debian・Ubuntu）: `sudo apt install ./sedum-note_0.7.0_linux-amd64.deb` で入れます。
- Linux（Fedora など）: `sudo dnf install ./sedum-note_0.7.0_linux-x86_64.rpm` で入れます。
- Linux（入れずに使う）: `chmod +x sedum-note_0.7.0_linux-x86_64.AppImage` のあと、そのファイルを開きます。
- Android: `sedum-note_0.7.0_android-arm64.apk` を開きます。v0.6.0 の上に入れられます。
- Web 版: https://aida0710.github.io/sedum-note/ を開きます。

ファイルの SHA-256 は `SHA256SUMS` にあります。`latest.json` と `.app.tar.gz` は、アプリが自分を更新するときに使うファイルです。

## 気を付けること

- v0.7.0 のデバイスが一度同期すると、同じ同期先を使う v0.6.0 のデバイスは「新しいバージョンのアプリで書かれています」と出して、更新するまで同期を止めます。写真に幅を持たせたので、データの形の版を 14 から 15 に上げたためです（古いアプリは、写真の幅を消してしまいます）。Web 版は、このリリースを出した時点で v0.7.0 に変わります。Web 版で同期している場合は、Web 版を開いて同期した時点で、ほかの v0.6.0 のデバイスが止まります。
- v0.6.0 のメモは書き換えずにそのまま開けます。
- v0.7.0 で書き出したバックアップは、v0.6.0 では戻せません。
- アプリ内の AI は設定の「AI」のページの「AI に任せるメモの操作」に従って、メモを探して読み、作って直し、ゴミ箱に入れます。既定では、探す・読むは聞かずに行い、作る・直すとゴミ箱に入れるのは毎回聞き、完全な削除は許可しません。AI が読んだメモの本文は、暗号化されない形でつなぎ先（Claude の API や OpenAI 互換のサーバー）へ送られます。
- v0.6.0 で残した AI の会話は、v0.7.0 では開けず、読み込むときに消えます。会話の残し方を変えたためです。
- メモの「アウトライン表示」をやめました。アウトライン表示にしていたメモは、本文が箇条書きのまま、ふつうのメモとして開きます。
- 本文の文字の大きさの「小・中・大」の設定は、標準（16px）に戻ります。設定の「一般」のつまみで選び直してください。
- ズームするキーを Ctrl+Alt+Z から Ctrl+.（Mac は ⌘+.）に、1 つ上の階層へ戻るキーを Ctrl+Alt+Shift+Z から Ctrl+Shift+. に変えました。

## 足したもの

### アプリ内の AI
- チャットの AI に、MCP と同じメモの道具を渡しました。AI は、結果を見ながら、メモを探して読み、作って直し、ゴミ箱に入れることを続けて行えます。答えの中には呼び出しを 1 行ずつ出し、押すとそのメモを開きます。
- 毎回聞く操作は 1 つの答えの分を 1 枚の承認のカードにまとめ、カードで選んだ操作だけを行います。本文を直す操作は消す行と足す行の行頭に「-」「+」を付けた差分で見せます。承認を待つ間に対象のメモが変わったら、その操作は行いません。
- AI がメモを直したあとも、開いているエディタの Ctrl+Z で 1 回で戻せます。
- 止めるボタンは答えを受け取っている間、承認を待っている間、操作をしている間のどこでも効きます。チャットの欄を閉じても、発言は止まりません。
- 設定の「AI」のページに「AI に任せるメモの操作」を足しました。「メモを探す・読む」「メモやノートブックを作る・直す」「ゴミ箱に入れる・ノートブックを消す」「完全に削除する」のそれぞれで、「許可しない」「毎回聞く」「聞かずに行う」を選べます。
- 本文で文字を選んだときに出るボタンに「AI に頼む」を足しました。選んだ所の言い換え・要約・英語への翻訳・日本語への翻訳を頼み、答えで選んだ所を入れ替えられます。
- チャットの上のモデルの選択と、チャットの下の「この会話では、メモを作る・直すときに承認を待たない」は、その会話だけに効きます。設定は書き換えません。新しい会話と、残した会話を開いたときは、設定のとおりに戻ります。
- 「保存して確かめる」のあとに、使うモデルを知らせます。前に選んでいたモデルが一覧に無く、別のモデルを選び直したときは、そのことも知らせます。
- AI チャットの「まだ有効になっていません」の案内から、設定の「AI」のページを開けます。

### 書く画面
- 書式のボタンは、文字を選んだときだけ、選んだ所の上に出します。写真・ファイル・表・コード・録音などは「/」から入れます。スマホの下のツールバーは今までどおりです。
- 本文の文字を 16px にし、行の間と字の間を広げました。設定の「一般」で、本文の文字の大きさ・字の間・行の間をつまみで選べ、見本で見え方を確かめられます。
- ブロックの左の持ち手を押すと、ブロックのメニューが開きます。本文・見出し・箇条書き・チェックリスト・引用・コードへの変換、上下への移動、複製、削除ができます。何行かを選んでいれば、まとめて変換します。持ち手の左の「＋」を押すと、下に行を足して「/」の候補を開きます。
- 持ち手を大きくし、マウスを近づける途中で消えないようにしました。
- Ctrl+Shift+↑↓（Mac は ⌘+Shift+↑↓）でブロックを上下に動かし、Ctrl+D ですぐ下に複製します。
- 「- 」「1. 」などで箇条書きにした直後に Backspace を押すと、打った文字に戻ります。
- 日本語入力のまま、行頭で「・ 」や「ー 」と打つと点の箇条書きに、「１． 」と打つと番号付きの箇条書きになります。
- 箇条書きと見出しを、全部たたむ（Ctrl+Alt+[）・全部開く（Ctrl+Alt+]）ことができます。メモの「…」からも選べます。
- 箇条書きの行頭の印を、深さごとに変えます（番号は 1. → a. → i.、点は ● → ○ → ■）。
- 本文で Tab を押しても、フォーカスが本文の外へ出ないようにしました。コードの中の Tab は行の字下げになります。
- 写真の右下の持ち手をドラッグして、大きさを変えられます。持ち手をダブルクリックすると、本文の幅に合わせる形に戻ります。

### ズーム
- ズームしている間は、題・タグ・目次などを隠し、PC ではメモの画面を窓いっぱいに広げます。左上の戻るボタンか Esc で、1 つ上の階層へ戻ります。
- 見出しのズームのボタンを、見出しの左に移しました。
- ズームしている間も、表のメニューと、録音を止めるボタンを出します。メモの中の検索でズームの外の言葉へ移ると、ズームをやめて見せます。

### 左の列と設定
- ノートブックをドラッグして、別のノートブックの中へ移せます。「ノートブック」の見出しへ落とすと、一番上の段へ移ります。
- ノートブックの「…」と右クリックのメニューに「中にメモを追加」を足しました。
- ゴミ箱の自動削除を有効にしたときと日数を変えたときは、いま消えるメモがあれば、件数を出して確かめます。日数は Enter か「保存」で決めます。
- MCP のトークンを作り直す前と、プロパティを削除する前に確かめます。プロパティの名前と選択肢は Enter か「保存」で保存し、保存せずに閉じるときは確かめます。

## 直したもの

- 見出しを開け閉めしたり、ブロックへリンクを張ったりしただけでは、メモの更新日時を変えないようにしました。これまでは、そのたびに「更新した順」の並びが動き、中身の同じ履歴が増えていました。
- AI と MCP の設定で、続けて変えた値が先に押した操作の古い値で上書きされることがあったのを直しました。
- 2 台で逆向きにノートブックを移して親子が輪になっても、輪の中のノートブックが左の列から消えないようにしました。

## 確かめた環境

- Web 版: Chromium と WebKit で、画面の試験を通しました。v0.6.0 の Web 版で作ったデータ（同期・添付・写真・履歴あり）を v0.7.0 で開き、v0.6.0 で入れた写真の大きさを変えて同期できることを Chromium で確かめました。そのとき、同じ同期先の v0.6.0 のデバイスが同期を止めることも確かめています。
- アプリ内の AI は決まった答えを返す偽の応答で確かめました。Claude の API と OpenAI 互換のサーバーへの実際の呼び出しは確かめていません。
- Windows・macOS・Linux・Android: 組み立てと、macOS で起動して最初の画面が出るところまでです。このリリースで足した機能は、アプリと実機では確かめていません。
- iPhone の Safari は確かめていません。
