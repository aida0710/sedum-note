同期の仕組みを作り直しました。デバイスのパスフレーズと、同期に使う暗号化キーを分け、アプリではバケットの CORS の設定が要らなくなりました。左の列でメモをドラッグして移せるようにし、アプリのアイコンも新しくしています。

**v0.2 までの同期先は、このバージョンでは使えません。** 移し方は、下の「v0.2 から移る」にあります。デバイスの中のメモは、そのまま開けます。

## 入れ方

- Windows: `sedum-note_0.3.0_windows-x64-setup.exe` を開きます。署名していないので「Windows によって PC が保護されました」と出たら、「詳細情報」を押してから「実行」を押します。
- macOS: `sedum-note_0.3.0_macos-universal.dmg` を開き、Sedum Note を「アプリケーション」へ移します。Apple の公証を受けていないので、初めて開くときに止められます。「システム設定」の「プライバシーとセキュリティ」で「このまま開く」を押してください。
- Linux（Debian・Ubuntu）: `sudo apt install ./sedum-note_0.3.0_linux-amd64.deb` で入れます。
- Linux（Fedora など）: `sudo dnf install ./sedum-note_0.3.0_linux-x86_64.rpm` で入れます。
- Linux（入れずに使う）: `chmod +x sedum-note_0.3.0_linux-x86_64.AppImage` のあと、そのファイルを開きます。
- Android: `sedum-note_0.3.0_android-arm64.apk` を開きます。v0.2 の上に入れられます。
- Web 版: https://aida0710.github.io/sedum-note/ を開きます。

PC 版の v0.2 を入れている場合は、「設定」の「更新」から入れ替えられます。ファイルの SHA-256 は `SHA256SUMS` にあります。`latest.json` と `.app.tar.gz` は、アプリが自分を更新するときに使うファイルです。

## v0.2 から移る

v0.2 までの同期先には暗号化キーが無いので、このバージョンでは「使えない」と出て、同期が止まります。次の順で移してください。

1. メモが全部そろっているデバイスを 1 台選び、v0.3.0 に上げます。
2. そのデバイスの「設定」→「同期」→「同期先を変更」を開きます。同じバケットの、空のフォルダを入れて「接続を確認」を押します。
3. 暗号化キーを「自動で生成する」か「自分で入力する」かを選び、そのデバイスのパスフレーズを入れて保存します。生成したキーは 1 度だけ表示されるので、控えます。
4. メモが新しい同期先へ送り直されます。前の同期先にある添付も、新しい同期先へ写します。
5. ほかのデバイスは、v0.3.0 に上げたあと、同じく「設定」→「同期」→「同期先を変更」で新しい同期先を入れ、「接続を確認」を押します。「このデバイスのメモと同じものです」と出るので、そのまま保存します。暗号化キーは要りません。そのデバイスにしか無かったメモも、新しい同期先へ送られます。

前の同期先のフォルダは、移し終えたら、ストレージの側で消せます。

## 変えたもの

- パスフレーズと暗号化キーを分けました。
  - パスフレーズは、そのデバイスのロックを解除するためのものです。デバイスごとに決められ、変えても同期先とほかのデバイスは変わりません。同期先には置きません。
  - 暗号化キーは、同期するデバイス全部で共通です。同期先を作るときに、自動で生成するか、自分で入力するかを選びます。ほかのデバイスは、このキーで参加します。
  - 暗号化キーは「設定」で作り直せます。参加済みのデバイスは、そのまま同期を続けられます。
- 「新しく始める／既存のメモに参加」の選択をなくしました。同期先を入れて「接続を確認」を押すと、そこが空か、既存のメモがあるかで、次に入れるものが決まります。
- フォルダを入れずに「接続を確認」を押すと、バケットの直下とそのすぐ下のフォルダから既存のメモを探します。1 か所だけ見つかれば、そこを同期先にします。
- アプリ（Windows・macOS・Linux・Android）では、バケットの CORS の設定が要らなくなりました。Web 版は、これまでどおり要ります。入れる設定は、Web 版の画面に出ます。
- アプリのアイコンを新しくしました。

## 足したもの

- 強いパスフレーズの生成（最初の画面と、パスフレーズの変更）。
- 自動の同期の入り切り。デバイスごとの設定で、切っても「今すぐ同期」は使えます。
- 同期に続けて失敗する間は、やり直す間隔を 5 分まで延ばします。アクセスキーが断られたときなど、待っても直らない失敗では、自動の同期を止めて理由を出します。
- 左の列のメモ（PC の画面）: ドラッグして、ノートブック・お気に入り・テンプレート・ゴミ箱へ移せます。メモの「…」か右クリックから、名前の変更、お気に入り、ピン留め、ゴミ箱への移動ができます。
- メモをゴミ箱に入れると、その場で元に戻せる知らせが出ます。
- タブの並べ替えと、左の列の幅の変更（PC の画面。ドラッグで行います）。

## 直したもの

- 「/」のメニューに、要らないスクロールバーが出ていました。
- 画面の「E2EE」と「暗号化して同期」の印をなくしました。

## 気を付けること

- 生成した暗号化キーは、あとから表示できません。失くしたときは、「設定」の「暗号化キー」で作り直します。
- 暗号化キーを作り直しても、メモは暗号化し直しません。前のキーと、作り直す前の同期先の鍵の情報（`vault.json`）の写しを持っている人は、これからのメモも読めます。
- 同期先を別の場所へ付け替えるとき、前の同期先につながらないと、そのデバイスで開いたことのない添付は新しい同期先に届きません。

## 確かめた環境

- Web 版: Chromium と WebKit で、画面の試験を通しました。
- Linux: 組み立てたアプリで、同期先の確認から作成、暗号化キーの表示、同期までを確かめました。CORS でアプリからの接続を断るバケットにも同期できました。
- Android 16（エミュレーター）: 配布用と同じ作りの APK で、CORS でアプリからの接続を断るバケットに同期できました。確かめたのは、同期の設定の画面を作り直す前の作りです。実機は確かめていません。
- Windows・macOS: 組み立てと、macOS で起動して最初の画面が出るところまでです。左の列のドラッグは、Windows と macOS のアプリではまだ確かめていません。
- Cloudflare R2: 同期の結合試験を通しました。
