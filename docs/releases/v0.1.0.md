memo-app の最初のリリースです。S3 互換のストレージで同期する、エンドツーエンド暗号化（E2EE）のメモ帳で、Windows・macOS・Linux・Android のアプリと Web 版があります。

メモ・ノートブック・写真はこのデバイスで暗号化してからストレージへ送ります。ストレージに置かれるのは暗号文とランダムな ID だけで、タイトルやノートブックの名前も見えません。同じパスフレーズを入れたデバイスだけが読めます。

## 入れ方

- Windows: `memo-app_0.1.0_windows-x64-setup.exe` を開きます。署名していないので「Windows によって PC が保護されました」と出たら、「詳細情報」を押してから「実行」を押します。
- macOS: `memo-app_0.1.0_macos-universal.dmg` を開き、memo-app を「アプリケーション」へ移します。Apple の公証を受けていないので、初めて開くときに止められます。「システム設定」の「プライバシーとセキュリティ」で「このまま開く」を押してください。Apple シリコンと Intel のどちらの Mac でも動きます。
- Linux（Debian・Ubuntu）: `sudo apt install ./memo-app_0.1.0_linux-amd64.deb` で入れます。
- Linux（Fedora など）: `sudo dnf install ./memo-app_0.1.0_linux-x86_64.rpm` で入れます。
- Linux（入れずに使う）: `chmod +x memo-app_0.1.0_linux-x86_64.AppImage` のあと、そのファイルを開きます。Ubuntu 24.04 以降で起動しないときは、`sudo apt install libfuse2t64` で FUSE を入れてください。
- Android: `memo-app_0.1.0_android-arm64.apk` を開きます。ブラウザやファイルのアプリに「不明なアプリのインストール」を許可してください。64 ビットの ARM の端末向けです。
- Web 版: https://aida0710.github.io/memo-app/ を開きます。インストールは要りません。

ファイルの SHA-256 は `SHA256SUMS` にあります。

## 初めて使うとき

1. S3 互換のストレージにバケットを作り、CORS を設定します。設定の例は [README](https://github.com/aida0710/memo-app#同期先の用意) にあります。Web 版を使うときは、`AllowedOrigins` に `https://aida0710.github.io` も足してください。
2. 1 台目では「新しく始める」を選び、パスフレーズとストレージの接続先を入れます。
3. 2 台目からは「既存のメモに参加」を選び、同じパスフレーズと接続先を入れます。

ストレージは、条件付きの書き込み（`If-Match`・`If-None-Match`）を守るものが必要です。アプリはつなぐときにこれを確かめ、守らないストレージは同期先にしません。

## できること

- ノートブック（入れ子にできます）、お気に入り、ピン留め、ゴミ箱でメモを整理できます。PC の画面では、左のノートブックの中にメモが並び、開いたメモはタブで切り替えられます。
- 本文に `#言葉` と書くと、その言葉がタグとして左の列に出ます。
- 見出し、太字、箇条書き、チェックリスト、リンク、コードを書けます。
- 写真は画像のボタン、貼り付け、ドラッグで本文に入れられます。Android では写真の選択画面から選びます。写真も 1 枚ずつ暗号化して同期します。
- オフラインでも書けます。編集の 2 秒後と 60 秒おきに同期し、回線が戻ったときと、アプリに戻ったときにも同期します。
- 2 台で同じメモを同時に変えたときは、どちらの本文も残します。ストレージにある方をそのまま残し、もう一方は「（競合コピー）」の付いた別のメモになります。
- パスフレーズは「設定」で変えられます。ほかのデバイスにも次の同期で伝わります。

## 気を付けること

- パスフレーズを忘れると、どのデバイスからもメモを読めなくなります。運営者のいる仕組みではないので、取り戻す方法はありません。
- メモを平文で書き出す機能と、ほかのアプリから読み込む機能はまだありません。
- Android のアプリから、カメラを開いてその場で撮ることはまだできません。撮った写真を選択画面から選んでください。
- 写真は元のファイルのまま暗号化して送ります。大きな写真を多く貼ると、ストレージの容量と通信量が増えます。
