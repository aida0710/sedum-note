スマホで押しにくい所と、押したままに見える所を直しました。

v0.8.0 のデータと同期先は、そのまま使えます。データの形は変えていないので、v0.8.0・v0.7.0 のデバイスと同じ同期先で一緒に使えます。PC 版の v0.8.0 を入れている場合は、設定の「更新」から入れ替えられます。

## 入れ方

- Windows: `sedum-note_0.8.1_windows-x64-setup.exe` を開きます。署名していないので「Windows によって PC が保護されました」と出たら、「詳細情報」を押してから「実行」を押します。
- macOS: `sedum-note_0.8.1_macos-universal.dmg` を開き、Sedum Note を「アプリケーション」へ移します。Apple の公証を受けていないので、初めて開くときに止められます。「システム設定」の「プライバシーとセキュリティ」で「このまま開く」を押してください。
- Linux（Debian・Ubuntu）: `sudo apt install ./sedum-note_0.8.1_linux-amd64.deb` で入れます。
- Linux（Fedora など）: `sudo dnf install ./sedum-note_0.8.1_linux-x86_64.rpm` で入れます。
- Linux（入れずに使う）: `chmod +x sedum-note_0.8.1_linux-x86_64.AppImage` のあと、そのファイルを開きます。
- Android: `sedum-note_0.8.1_android-arm64.apk` を開きます。v0.8.0 の上に入れられます。
- Web 版: https://aida0710.github.io/sedum-note/ を開きます。

ファイルの SHA-256 は `SHA256SUMS` にあります。`latest.json` と `.app.tar.gz` は、アプリが自分を更新するときに使うファイルです。

## 直したもの

- スマホのロックの画面で、カードが画面の上に寄っていて押しにくかったので、縦の真ん中に置きました。
- スマホの下のツールバーで、何も無い行で箇条書きのボタンを 2 回押すと、2 回目は「インデントを減らす」に当たり、箇条書きのボタンが押したままに見えていました。箇条書きにしてもボタンの位置がずれないようにしました。
- スマホで、押したボタンや行が、押したまま・選んだままの見た目で残ることがありました。マウスを乗せたときの見た目は、マウスのある端末だけで出すようにしました。
- メモの本文の上に出る「未送信」の文字が、色の付いた背景の左の端からはみ出していました。

## 確認した環境

- Web 版: Chromium と WebKit で、画面の試験を通しました。
- Windows・macOS・Linux・Android: 組み立てと、macOS と Linux で起動して最初の画面が出るところまでです。このリリースで直した所は、アプリと実機では確認していません。
